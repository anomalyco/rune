- **`Tx::hovered` and `Tx::is_hovered` query what the pointer is currently over from any handler or `poll`.** `Tx::hovered()` returns the key of the innermost hovered element (or hovered `Link` id; `#n` when only an unkeyed hit element is hovered), and `Tx::is_hovered(key)` reports whether the pointer sits over `key` or any descendant (CSS `:hover`), resolving the same keys and `/`-separated key paths as `Tx::focus_within` while respecting hit occlusion, `El::hover_passes_below`, modals, `El::inert`, `HoverHold`, held-press capture, touch, and exiting/unmounted subtrees.
