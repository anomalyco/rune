- **`El::cutout_circle` punches a round hole through an element and its subtree.** Clear within one radius of a centre (in points from the element's top-left, inside it or not), whole from another, and linear between, as CSS `mask-image: radial-gradient(circle at x y, transparent 4px, black 5px)` does for OpenCode's avatar unread dot. The subtree draws in an isolated layer, and the layer's composite cuts the hole in the uber shader, in the same window device pixels as its clip, so it follows the element anywhere; the CPU reference (`rune-ref`) cuts it the same way. `cargo run -p rune --example regen_dxbc` regenerates the precompiled DX12 uber shader on Windows without building Rune's unit tests, and the bytecode is regenerated for this change.
