- **Windows: a window covered whole by other windows rests, as Chromium's occluded windows do.** A tracker thread hears windows move, show, hide, minimise and switch virtual desktop (`SetWinEventHook`) and walks the z-order a frame later; a window none of whose rect shows, minimised, or on another virtual desktop is covered: it draws nothing and runs no motion, `App::on_visibility` hears it hide, and uncovering paints the settled state. Only on the desktop the user sees, so a capture harness's hidden desktop keeps drawing. What covers a shown window (the system's word, a refused drawable, other windows) is one machine, `window::Sight`.
