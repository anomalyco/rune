- **A layer pipeline the GPU refuses no longer blanks the frame.** The pipelines an isolated layer needs (its `Rgba16Float` target's, the composites, `Blend::PlusLighter`'s and the layer blur's) are built in error scopes the first time a frame needs them, and used only once the device has taken them. One it refuses is dropped, logged once and not built again, and frames draw without it: an isolated group straight into its parent (without its opacity, blur, rounded clip or turn), a dissolve as source-over, a blur unblurred. Before, the refused pipeline stayed cached and invalidated every frame's command encoder, so a web app hit `[Invalid RenderPipeline "uber"]` every frame on a blank canvas once a group first faded. On the web the browser answers a moment later, so a frame or two draw the fallback while it does.
