- Links: added `Tx::open_url_then` and `Tx::open_url_same_tab_then`, which run a callback on a later frame with what came of the open (`Ok(())`, or `OpenUrlError::Failed` when macOS or Windows couldn't open it, `xdg-open` couldn't start, or the browser blocked it), for an inline error or a link to copy. On web, `rune::web::open_url` now returns an error when no click or key press is active, since browsers block the tab then, and `Tx::open_url_then` passes that error to its callback (`Tx::open_url` only logs it); the tab still opens with `noopener,noreferrer`, which hides other pop-up blocks.
