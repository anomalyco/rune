- **`Cursor::ZoomIn` and `Cursor::ZoomOut`: the system's magnifier cursors (CSS `zoom-in` / `zoom-out`)**, at the size of every other system cursor. Markdown images use `ZoomIn` instead of their own 32 pt magnifier picture, which looked twice the size of the arrow beside it.
- **rune-kit `Preview`: closing it in the last frames of a zoom still animates.** A glide's frames no longer mark the whole commit instant (the image lands on its own with `El::instant_changes`), so an Escape while the fit still glides flies the image home instead of snapping it there. The zoom level's button is wide enough for three digits, so the bar no longer shifts as the level passes 100%.
