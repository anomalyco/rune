- **`single_instance` reaches the running app from a macOS executable outside a bundle.** Launch Services keeps one process per app bundle and hands it links, but a `target/debug` build or a launcher script's executable got neither: a second launch started a second app, and the link it carried went nowhere. Such a process now claims the per-user socket Linux uses (in `/tmp/rune-<uid>`, mode 0700), so a later launch's links go to the first one's `App::on_open_url` (and a launch without links reopens it), and the links a first launch was started with reach its own `App::on_open_url`. A process started from its bundle is unchanged.
