- **Tooling: deterministic headless `FontSmoothing::On` and `--font-smoothing MODE` CLI flag.** Headless runs (`--snap`, `--frames`, `--video`, `--strip`, `--desktop`, `--snap-on-patch`, `App::headless_runtime`) no longer downgrade `FontSmoothing::On` to `Off` when the host Mac has `AppleFontSmoothing = 0` (globally or in `-currentHost` / ByHost preferences), matching how headless isolates theme, scale, scroll bars and accessibility preferences from the machine's user settings. Added `--font-smoothing MODE` (`on`, `off`, `windfoil`, `windfoil-chromium`, `windfoil-rgb`, `slug`, `hinted-gpu`, `hinted`, `direct-write`, `clear-type`) to override an app's font smoothing from the command line without rebuilding.
