- **`TreeStyle` styles an editor's file tree.** `chevron_only_folders` drops the folder icon so folders show only their chevron and a file's icon takes the chevron's lane; `chevron`, `chevron_colors` and `chevron_nudge` choose the disclosure glyph, its rest and selected colours and its offset; `label` sets the names' font and rest and selected colours; `fade_long_labels` fades a long name out instead of ending it in an ellipsis; `guides_on_hover` hides the indent guides until the pointer is over the tree; and `hover`, `gap` and `radius` set the row overlay, spacing and corners. Defaults keep today's look.
