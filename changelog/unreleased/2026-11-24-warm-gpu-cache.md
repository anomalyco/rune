- `rune::warm_gpu_cache()` (Windows): makes what a window's GPU frames start from (the device, the renderer's pipelines for a window's swap chain, the pinned pipelines) in a process that shows nothing, and returns once the driver has compiled them. Direct3D keeps the driver's compiled pipelines and its own shader-cache databases per user and per exe path, so a setup can run the installed program once in a mode that calls this and exits: the person's first launch then takes its window over to the GPU as a later launch does. Without it a first launch pays for Direct3D making those databases inside `D3D12CreateDevice` (184 flushed commits: 0.5 s and more on a consumer disk) and for the driver compiling each pipeline. Elsewhere it does nothing.
