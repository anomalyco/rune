- **Split diffs show an added or deleted file in one column.** `DiffView` in `DiffMode::Split` draws an added file's new side, or a deleted file's old side, across the whole width, with no empty half beside it, as Desktop's review does. `FileDiff::sole_side()` names the one side a file has (from its status, or a text diff with one empty side), and `DiffState::single_column(file)` says when split mode draws a file that way.
