- Text: `AppSpec::new` and `TextSystem::default` now default the mono slot to `"ui-monospace"` (`("Inter", "ui-monospace")` on native; web keeps `IBM Plex Mono`), so `Family::Mono`, `TextStyle::mono()`, `rune_kit::Cell::mono()` and `Kit::ty.mono` render in the platform's monospaced UI face instead of proportional Inter. System monospace fonts load lazily only when mono text is first laid out, so launch and sans-only first frames load no system fonts.
