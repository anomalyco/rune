- **rune-luau: a script made from sources an app ships can start without compiling them.** `rune_luau::precompiled` takes the app's ahead-of-time bytecode as `(source, bytecode)` pairs (compiled with Rune's settings: optimisation 2, type information 1, debug 1); `Sources::compile` uses a module's bytecode when its text matches and compiles the rest as before. A table from another Luau bytecode version is ignored. Compiling was most of a script's start: OpenCode (Rune)'s 16 built-in plugins took 213,001 µs p50 to start before its first window's first frame on a Windows laptop, and 87,365 µs from precompiled bytecode.
