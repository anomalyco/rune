- **`rune::credentials` keeps a secret in the platform's credential store.** `Credentials::system()` writes, reads and deletes an account name and secret bytes keyed by a service name: in the Keychain on macOS and iOS, Credential Manager on Windows and the Secret Service on Linux (with the `dbus` feature, under the `xdg:schema` `dev.rune.Credential`), and returns `CredentialError::Unsupported` on the web and Android. A failed write leaves the old credential. Calls block, so run them off the UI thread (`Latest::request`). Headless runs, `App::headless_runtime` and `RUNE_CREDENTIALS=memory` get one in-memory store per process, while windows, overlays and an app's own `Runtime::new` keep the platform's store; a test that drives `Runtime::new` itself uses `Credentials::memory()`, a store of its own, or `RUNE_CREDENTIALS=memory`, and `Credential`'s `Debug` redacts the secret.
