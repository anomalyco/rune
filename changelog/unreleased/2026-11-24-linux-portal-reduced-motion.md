- Linux: `Cx::system_reduced_motion()` now follows the XDG Settings portal (`org.freedesktop.appearance` `reduced-motion` and `org.gnome.desktop.interface` `enable-animations`) on the shared appearance-portal worker thread with live `SettingChanged` updates, and falls back at most once off the UI thread to `kdeglobals` or GSettings only when the portal answers neither key (or when the `dbus` feature is off), removing synchronous file I/O and `libgio` loading from focus changes on the UI thread.
