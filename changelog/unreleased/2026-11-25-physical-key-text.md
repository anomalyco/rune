- **Physical keys carry the platform's text.** `PhysicalInput::Key` gains `text: Option<String>`, the text the platform typed for the key (`None` for a release, an arrow or a dead key that hasn't composed), and `consumed_mods: Mods`, the modifiers spent producing it: Alt when the text differs from the unmodified key, Shift when it does and Ctrl isn't held, Ctrl and Alt for a Windows AltGr, never `logo`, and nothing for control text such as Enter's `"\r"`. Desktop windows, overlays, Wayland layer-shell overlays and the web host fill both; a key queued with a logical `Key::Text` and no `text` (scripts, `Runtime::key_with`) gets that text. `PhysicalInput` is no longer `Copy` (clone it), `text` is zeroized on drop, and a `PhysicalInput::Key { .. }` literal now names `text` and `consumed_mods` (`text: None, consumed_mods: Mods::default()`).
