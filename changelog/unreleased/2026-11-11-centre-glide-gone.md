- **A `Tx::scroll_center` glide stops once its target is removed for good.** Removing the element it was centring used to leave the glide running to where the element had been. Now the glide comes to rest where it is once the target has been unmounted at two frame ends running and isn't a row of a virtual list there, or inside the row it was mounted in. A target still playing its exit counts as there, so undoing the removal mid-exit keeps the glide going, as does a virtual row out of the list's window or an element remounted under its key on the next frame.
