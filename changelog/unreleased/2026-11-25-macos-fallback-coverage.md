- Text fallback & macOS startup: `TextSystem::load_fallbacks` now checks glyph coverage against the active resolved families in `FontContext` (including installed system fonts, runtime-registered fonts, slot fallbacks, and per-span monospace stacks) before querying platform fallback or loading math fonts for non-alphanumeric symbol characters such as `≥`; on macOS, `load_slot_fallbacks` loads only the system UI text family (`System Font` / `.SF NS`) and defers `Apple Color Emoji` until emoji text is shaped.
