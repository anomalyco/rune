- rune-luau: hosts get the API a plugin platform needs. `ScriptOptions::start` runs with each new VM and its entry's table, `around`/`around_read` wrap entries from the UI with the app's state, `Sources::entry` starts from another module, and `Script::render_fn`/`spawn_fn`/`eval_fn` render, run and query functions a script handed over. Host nodes take a leading string, one child node, table props (`Prop::Data`), palette colours and event fields. Props add `pin`, `corners`, `shadow`, `selected`, `focusable`, `disabled`, `helpSide`, `hoverTransition`, `hoverGroup`, `hoverGroupColor`, `revealOnHover`, `onHover` and `fadeOut`; `ScriptOptions::text` sets the base text style and the weights. `ScriptOptions` moved to `options.rs`; its public API is unchanged.
