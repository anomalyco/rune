- **Windows apps get their links and keep one process.** `App::on_open_url` now runs on Windows for the links among the launch arguments (`scheme://…`), as it does for the launching link on macOS, and `rune::single_instance(id)` (call it first in `main`) makes the first process of the app the only one: a later launch hands its arguments to it over a per-user named pipe, lets it take the foreground, and returns false so `main` returns. Its links reach `on_open_url`; a launch without links reopens the app (`on_reopen`, then the default, which on Windows also brings the front window forward, restored). Links that arrive before the event loop starts are kept for the first window with the hook. Elsewhere `single_instance` returns true.
