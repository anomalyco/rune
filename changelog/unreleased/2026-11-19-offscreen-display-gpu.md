- **Offscreen and test work draws on the GPU a window would get: the one driving the primary display.** It took the lowest-power adapter, which on a desktop is often an integrated GPU no monitor uses: on one machine 113 times slower than the discrete card beside it, where a test's single submission ran past Windows' 2-second limit and reset the GPU. A hybrid laptop whose panel is on its integrated GPU keeps that GPU (it drives the primary display), so its discrete GPU stays asleep; with no display GPU found (a headless server, a remote session) Rune still takes the lowest-power adapter. `WGPU_ADAPTER_NAME` now also finds software adapters (`Microsoft Basic Render Driver`, WARP) on Windows. `RUNE_GPU_LOG=1` names the new reason, "the GPU a window would get".
