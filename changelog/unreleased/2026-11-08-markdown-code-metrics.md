- **Markdown: inline code, images under headings and plain code blocks match a page.** Inline code's padding spaces now take exactly `inline_code_pad` points a side in the text's own font (they were about a point and a half wider, so text after a code span sat further right), an image keeps its 24-point top margin under a heading as a page's collapses it through its paragraph, and `MarkdownStyle::plain_code_text` colours fences with no language (or `text`, `txt`, `plain`, `plaintext`) apart from highlighted ones.
