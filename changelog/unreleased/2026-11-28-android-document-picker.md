- Android document picker over `FileHandle`: `RuneView` / `RuneActivity` now serve `Tx::pick_file`, `Tx::pick_files` (`ACTION_OPEN_DOCUMENT`) and `Tx::pick_save_file` (`ACTION_CREATE_DOCUMENT`) via Storage Access Framework `content://` URIs backed by a `FileHandleProvider` over `ContentResolver.openFileDescriptor(..).detachFd()`, while refusing path-based and folder dialogs with an error; embedding hosts with their own `Activity` can wire `RuneView.onDocumentPick` and return results through `onDocumentPickActivityResult` / `deliverDocumentPick`.
