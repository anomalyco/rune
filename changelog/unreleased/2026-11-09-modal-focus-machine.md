- **Modal focus is an explicit state machine, and keyboard focus is never on something unseen.** The open modals and where each hands focus back live in `ModalFocus` (`step(event) -> effects`), as a web dialog stack keeps them. A control inside a focus group's item (a tab's close button) is a Tab stop of its own rather than an item of the group. A `group_opacity` element shows at its hovered opacity while keyboard focus is on it or inside it, as CSS reveals a hover-only button on `:focus-visible`. `TabStrip::close_tab_stop(true)` makes each tab's close button a Tab stop with the kit's ring.
