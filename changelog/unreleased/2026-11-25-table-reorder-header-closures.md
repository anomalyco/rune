- `rune-kit` `Table`: added `Table::on_reorder(|s, from, to, tx|)` so dragging a header sideways moves its column (a press inside the 4 pt slop still sorts), with the order kept in `TableState::column_order` (`set_column_order`, `reset_column_order`, `move_column`, `visible_columns`); `Table::header(s, k)` builds only the header row, with its sorting, resizing, reordering and header hooks, to sit over rows an app draws itself, and `Table::visible_columns(s)` plus `TableState::laid_out_width` give those rows the shown columns, in order, and their resolved widths (`TableState::dragged_column` says which header is being dragged, and how far). `Table::new` now takes closures (`impl Fn`) instead of `fn` pointers, so its accessors can capture, for example several tables over one app state; closures and functions that compiled before still compile.
