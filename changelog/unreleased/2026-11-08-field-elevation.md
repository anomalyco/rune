- **Text fields and field selects take `@opencode/ui`'s own field shadow, and a focused field select drops its shadow and hover tint, as `select.css` does.** `Elevation::with_input` sets the fields' shadow (`--v2-elevation-input`), which `TextInput`, `Textarea` and a field `Select` draw instead of a neutral button's; in OpenCode's dark theme it's lighter (no drop, a 16% light ring), and the OpenCode theme now carries it. `Elevation::input` reads it, falling back to `button_neutral`. `El::focus_within_flat` makes an element draw none of its box shadows and no hover fill while focus is on it or inside it, as a CSS `:focus-within { box-shadow: none }` field whose hover is `:not(:focus-within)`; a field `Select` focused from the pointer or the keyboard uses it, showing only its focus ring. Breaking: `Elevation` has a private field, so build one from `Elevation::default()` and set its fields rather than as a struct literal.
