- **A small RGBA image is ready at once, and the decoder threads don't start on the caller's thread.** `ImageCache::rgba` of 64x64 pixels or fewer finishes its mips on the calling thread, so a view draws it in the same frame rather than a placeholder first. The first image to decode starts one decoder thread, which starts the other three. OpenCode's first frame made its first project tile this way, and paid for four thread starts on the UI thread. First `rgba` call in a process: 241-395 µs before, 127-181 µs after.
