- Headless runs and GPU tests: `App::try_run`, `try_run_windows_with`, `try_run_windows_with_args` and internal headless helpers now return `Err` on GPU or renderer setup failure instead of calling `std::process::exit(2)` mid-process while CLI `run` / `run_windows_with_args` preserve exit code 2; GPU and headless tests now route through a shared opt-in helper (`RUNE_ALLOW_NO_GPU=1`) that skips missing-adapter tests with a message or runs non-pixel GPU tests on `test-gpu-noop` while continuing to fail by default when no opt-in switch is set.
