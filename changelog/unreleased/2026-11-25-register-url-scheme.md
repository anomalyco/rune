- Apps: added `AppHandle::register_url_scheme(scheme)`, a future that makes the running app the system's default handler for a URL scheme, so links reach `App::on_open_url` even when another app claimed the scheme first. macOS 12+ calls `NSWorkspace` `setDefaultApplicationAtURL:toOpenURLsWithScheme:completionHandler:` for the running `.app` bundle; Windows writes the per-user `HKEY_CURRENT_USER\Software\Classes\<scheme>` entry for the running executable; Linux, web, iOS, unbundled macOS binaries and macOS before 12 answer `UrlSchemeError::Unsupported`. Headless runs and tests record the scheme for `Runtime::take_url_scheme_requests` instead of touching the system.
