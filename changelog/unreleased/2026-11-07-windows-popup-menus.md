- **Windows shows native pop-up and context menus.** `Tx::popup_menu` opens a `TrackPopupMenuEx` menu, with submenus, check marks, disabled items, separators and shortcut hints, and `popup_menu_supported()` is true there. The menu opens from a message posted after winit's handler returns, so Rune keeps drawing while it tracks. It drops down below an element anchor (a selected item isn't placed over the anchor, and there's no minimum width) and opens at a point anchor. Keyboard navigation is native, and Esc, a click outside or the window closing answer `None`.
