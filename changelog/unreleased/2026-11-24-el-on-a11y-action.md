- Accessibility: added `El::on_a11y_action` so composite containers (`listbox`, `tree`, `grid`, `table`, `menu`, `tablist`) that handle input on the container receive unhandled `accesskit::Action` requests sent to enabled descendants with the target's key (or path when unkeyed), bubbling innermost-first; actionable descendant composite items advertise `Action::Click` in AccessKit and mirror as clickable controls on the web while non-item and disabled descendants do not.
