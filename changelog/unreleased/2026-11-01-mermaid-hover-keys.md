- **A Mermaid diagram's hover areas keep their node or edge as it streams.** Each hover area is now keyed by the node or edge it lights, the same key its piece has (`hover:n:A`, `hover:e:A>B.0`, `hover:e:A>B.t` over the edge's label), not by its position in the drawing (`node1`, `edge0.1`). So when a streaming diagram's layout moves under a still pointer, the hovered node or edge stays lit as itself or lets go; it never turns into whichever node or edge took its index (a subgraph arriving around a placeholder node used to shift every later node down one).
