- Runtime and input API: added `Runtime::key_with` and made `Runtime::physical_key_input` public so embedders and headless test hosts can deliver key events with their physical key code (`Tx::physical_key`) and unmodified layout character (`Tx::key_base`); added `Tx::cancel_pointer` (deferred until after the calling handler finishes) and made `Runtime::cancel_pointer` public so apps and hosts can cancel an active pointer capture or drag cleanly, delivering a cancelled `Phase::Up` and clearing press and hover state.
