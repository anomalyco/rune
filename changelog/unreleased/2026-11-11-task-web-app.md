- **Web: a desktop app runs in the browser unchanged.** New `rune::task` (`spawn`, `spawn_after`, `serve`) runs work off the UI thread on every target: a named thread natively, as before, and on the web, which has no threads, a main-thread task after the current event (8 ms slices) with served channels drained after each event batch. `rune::time` gains `SystemTime` and `UNIX_EPOCH` (std's natively, `Date.now()` in a browser, where std's panic). The web runs `App::on_ready` once the first frame is presented, as a window does, where it refused the app.
