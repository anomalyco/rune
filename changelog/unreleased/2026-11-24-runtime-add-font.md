- **`rune::text::add_font`, `Tx::add_font`, and `Runtime::add_font` register font bytes at runtime** across Linux, macOS, Windows, and web without file I/O on the UI thread. Passing raw TTF, OTF, TTC, or variable font bytes (`impl Into<Arc<[u8]>>`) returns the registered family names in order, deduplicates identical blobs by content hash, ignores empty, unrecognised, or >64 MiB inputs, advances `rune::text::font_epoch()`, and updates `rune::text::measure`, existing windows and overlays, and newly opened windows so `set_font_families` or `Family::Named` can use the added family immediately.
