- **`rune-theme-opencode` ships every provider mark Desktop draws.** `provider_icons::named` now covers all 102 marks in `@opencode/ui`'s provider sprite (up from 21), so DigitalOcean, OpenRouter, Poe, Claude Agent, Meituan and the rest no longer fall back to the `synthetic` stand-in. `tools/provider-icons.py` reads the sprite and flattens each mark for Rune's icon subset: a viewBox that isn't square from 0 is centred in a square one, groups and transforms are baked into the path data, inherited paint is written on each shape, and clip paths are dropped. The few marks that paint their own colours (302.AI, Novita AI) keep them as `#rrggbb`, so they draw in colour as Desktop does. `NAMES` is now sorted by id.
