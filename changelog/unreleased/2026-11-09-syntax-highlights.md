- **Code highlights in 80 languages, token for token as OpenCode Desktop draws them.** `rune_kit::syntax`'s built-in highlighter is now Pierre's Highlights, the lexers Desktop colours diffs, files and Markdown with, which the new `rune-highlights` crate translates from WebAssembly to Rust at build time: C, C++, C#, Java, Kotlin, Ruby, PHP, Lua, Dockerfile, Makefile, Scala, Haskell, Elixir, Zig, PowerShell, Dart and the rest of its 80 languages and 211 names, at 0.1 to 0.6 ms per thousand lines, about 430 KB native and 175 KB gzipped on the web. A block that grows at its end (streaming in) lexes only its new lines. `Syntax` gains `Operator`, `Regex`, `Attribute` and `Variable`, `syntax::kind` maps each lexer token to the kind Desktop's theme colours it as, `SyntaxTheme::with_weight` lets a theme bold a kind (Desktop bolds Markdown headings), and `syntax::lang_for_path` names a file's language as Desktop's diffs do, which `FileDiff::language` now returns (`"rust"`, `"makefile"`). Colour stops after 128 KiB and 32,768 ranges per block, up from 32 KiB and 8,192. **Breaking:** the hand-written scanners are gone, so the built-in tokens change for the languages they covered (82.9% of their bytes were coloured as Desktop's); `FileDiff::language` returns Highlights' language names rather than the extension.
