- **`Menu` padding, separator spacing, inner border and separator keys can be set.** `Menu::padding` sets the padding around the rows (4 for `standard` menus, 2 otherwise), `Menu::separator_spacing(above, below)` the space around each separator (the padding by default), and `Menu::inner_border` the width of a `standard` menu's border (1 by default, 0 for none). `Menu::separator_keyed(key)` gives a separator its own key, so it no longer changes from `sep{index}` when an entry is added above it.
