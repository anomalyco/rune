- **A full-context patch folds like a diff of two texts.** `FileDiff::fold(context)` takes a diff whose one hunk holds the whole file (a patch made with full context, as `git diff -U<n>` or OpenCode's server writes) and splits that hunk around its changes with `context` unchanged lines each side, keeping the patch's own line pairing, and keeps the two texts it holds so `DiffView` can expand every folded range. A diff of any other shape comes back as it was. `FileDiff::text(side)` reads a diff's whole text of a side when it has one.
