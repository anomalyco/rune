- **Rune's own menu words follow the app's language.** `rune::set_labels(|label| ...)` names what Rune itself shows: a text field's menu (Cut, Copy, Paste, Select All, Learn Spelling, No Guesses Found, Spellcheck, Spellcheck Languages and each dictionary's language), selectable text's Copy, and on macOS the standard Edit and Window items, the app menu's items and the titles of the top-level menus Rune makes (`Label::Menu(name)`). A label the app leaves as `None` stays in English. `rune::labels::set_locale(tag)` says which language that is: on Windows the Spellcheck Languages submenu then names each dictionary in it and sorts them as it sorts text, through the system's ICU (`icu.dll`), as a browser's `Intl.DisplayNames` and `localeCompare` do. Field menus read the labels each time they open, and `AppHandle::set_menu` retitles the menu bar, so a language switch reaches both. Items still place themselves by the menu's name (`MenuItem::menu("Edit")`), whatever its title.
