- **On Windows, spell checking a text field checks only the words it hasn't checked before, so a key typed into a long draft checks one word, not the draft.** Each word's answer is cached per dictionary generation; new words go to the checker together. A 1,350-character draft's paint per key went from 7,184 to 1,700 µs p95. macOS still checks the whole text, which it reads the language from.
