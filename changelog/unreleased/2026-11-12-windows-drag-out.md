- **Windows: dragging out of a window works (`El::drag_out`).** Files, PNG data and text drag to Explorer, browsers and chat apps through OLE's `DoDragDrop` with a shell data object (files sharing a folder go as the shell's own item list, as Explorer's drags do, else `CF_HDROP`) and the shell's drag image (`IDragSourceHelper`): the element's snapshot or the item's image, or the shell's own picture of the files. The session runs from the message loop (posted, as the window menu is), so windows keep drawing while it's out; Escape cancels; the app's own windows refuse the drag unless `DragItem::within_app`.
