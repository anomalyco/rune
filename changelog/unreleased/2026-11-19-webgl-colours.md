- **Web: WebGL2 draws the same colours as WebGPU.** The WebGL2 surface now configures directly in `Rgba8Unorm` when `srgb_blend` is on (and `Rgba8UnormSrgb` when off, including across live `Tx::set_srgb_blend` switches) instead of keeping `wgpu-core`'s default `Rgba8UnormSrgb` surface while the runtime emits sRGB-encoded colours, eliminating the double sRGB encoding across every pixel; unsupported `COPY_SRC` canvas usage is no longer requested on WebGL2 when drift readback is enabled.
