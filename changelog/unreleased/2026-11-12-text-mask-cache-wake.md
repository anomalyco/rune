- **Text: the glyph mask cache is written even when the window rests after launch.** Its first write waited for a frame 3 s after the first one; a window that drew nothing more (opened, then left) never wrote its masks, so its next launch rasterised every glyph again. The first frame now asks for a wake when the write is due, and a timer's poll on a resting window writes it. Launch traces also count shaping before the first frame: `text.shaped` and `text.shape_ns` beside `text.raster_ns`.
