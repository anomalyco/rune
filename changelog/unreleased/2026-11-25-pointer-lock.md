- Pointer & input: added declarative `El::pointer_lock(|s, [dx, dy], tx| ..)` for relative mouse-look capture on desktop windows, `Cx::pointer_locked()` (invalidating views and memos on change), `Runtime::pointer_locked()`, `Runtime::pointer_motion(dx, dy)`, and `ScriptEvent::PointerMotion { dx, dy }` (`{"type": "pointer-motion"}`). Backed by an explicit `LockState` (`Off`, `Ready`, `Locked`) state machine whose opposite `Grab`/`Ungrab` effects cancel before host sync, with motion coalescing, `Tx::live_only()` support, frozen pointer/button routing while captured, Escape release (consumed, after drag cancel, on both logical and physical key paths), and automatic release on focus loss, unmount, modal cover, disabled, or inert states. Desktop hosts grab with `CursorGrabMode::Locked` falling back to `Confined` (hiding the cursor while locked and focused) and scale `DeviceEvent::MouseMotion` by `1/scale_factor` on Windows and X11; web, iOS, and overlays never capture.
