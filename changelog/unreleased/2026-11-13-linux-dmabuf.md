- **Linux: `NativeSurface::push_dmabuf` shows frames another process renders into dmabufs.** A producer renders BGRA8 into linear (or other explicit-modifier) single-plane dmabufs on the GPU `native_surface::linux::import_target` names; Rune imports each buffer once on its Vulkan device, copies a frame into its own texture the first time it draws it, and calls the frame's `on_read` once the GPU has finished that copy, so the producer knows when it may write the buffer again. Vulkan devices on Linux now enable `VULKAN_EXTERNAL_MEMORY_DMA_BUF` when the driver has it.
