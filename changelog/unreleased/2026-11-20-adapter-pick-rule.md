- **Offscreen and test work take the GPU a window would get, `WGPU_ADAPTER_NAME` is final, and `RUNE_GPU_LOG=1` logs every pick.** Without overrides or a compositor device, every device (windows, overlays, offscreen renders, tests and replacement devices after a loss) takes the GPU driving the primary display, falling back to lowest power only when no display GPU exists; hybrid laptops whose panel is on the integrated GPU keep it, while desktops whose monitors hang off a discrete card no longer send offscreen or test work to an idle integrated GPU. `WGPU_ADAPTER_NAME` now finds software adapters through DXGI on Windows (`Microsoft Basic Render Driver` for WARP) without creating a device on any other adapter, and fails with an error rather than falling through to another GPU when no adapter matches or the named adapter cannot create a device or present. `RUNE_GPU_LOG=1` prints every adapter pick in a process with its reason.
