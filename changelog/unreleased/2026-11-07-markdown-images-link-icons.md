- **Markdown draws images, link icons and parameters as OpenCode's `markdown.css` does.** An image (`![alt](src)`) is a block of its own (`Block::Image`): `Markdown::images` gives the app's picture for a source, drawn at its own size up to the text's width, rounded 4 and 24 points above and below, with a zoom-in cursor; until it decodes, or without one, Chromium's broken-image glyph and the alt text show. `Markdown::image_frame` wraps a shown image so an app can open it larger. `MarkdownStyle::link_icons(14.0, 4.0)` puts a globe (GitHub's mark for github.com) before each link to a web page, or the site's favicon from `Markdown::link_favicon`. Paragraphs and list markers keep their exact line heights, so long lists no longer drift a point per item, and wide tables measure cells unrounded without trailing spaces, so columns land where a browser puts them. Code highlighting colours a defined function's parameters as `Syntax::Parameter` (TextMate's `variable.parameter`), in the text colour by default.
