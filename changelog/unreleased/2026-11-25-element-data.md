- Point picking: added `El::data` to attach a typed value to an element (one per type; a second value of the same type replaces the first) and `Picked::data::<T>()` to read the nearest one at or above the picked element, so `Runtime::element_at*` and `Tx::element_at*` hits can say what a drop zone or row stands for without parsing keys. `Picked`'s `Debug` output now also prints how many attached values the hit path holds.
