- **macOS: which GPU work a GPU recovery aborted, and how long it had run.** `rune_gpu::metal::aborted(queue, submission)` says how long a stock wgpu Metal submission had executed when the GPU aborted it, as a GPU recovering from a hang does to everything it was running or held: the work that hung ran until the GPU stopped it (about 50 ms on an M5 Max), work queued behind it never ran. The vendored wgpu-hal records each aborted submission when it finishes (`metal::Queue::aborted`, the last 256 per queue) and counts it finished, or its device lost, only once recorded.
