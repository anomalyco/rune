- **`ImageCache::load` reads GIF, WebP, BMP and ICO, and AVIF with the new `avif` feature; GIF, WebP and APNG animate.** Every frame decodes on the cache's workers with its mip chain (browsers' timing: a frame of 10 ms or less shows for 100 ms; their loop counts), and a paint shows the frame for its time since the image first drew. The next frame wakes the window only while an element draws the image in a shown window, so an animation scrolled away, covered by a clip or in a hidden window costs nothing. The `avif` feature decodes with rav1d (NASM on the PATH for x86 builds); a web build keeps handing these formats to the browser, which shows GIF and WebP's first frame.
