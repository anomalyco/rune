- **A diff's removed and added lines pair as OpenCode Desktop's Pierre pairs them.** A run of changes with more lines on one side pairs its lines where they match best, not by position (`realignChangeContentBySimilarity`), so a line edited next to an inserted one sits beside its new version in split view and marks its word changes against it. Each run lays out its removed lines, then its added ones, block by block. `Line::pair` names a changed line's partner, and `Hunk::split_rows` lists a hunk's split rows (`SplitRow`).
