- **Wide markdown tables and code scroll as OpenCode's `markdown.css` does.** `MarkdownStyle::text_width` gives the text column's width: with `Markdown::scroll_wide`, tables then size their columns as a browser's automatic table layout does (in proportion to their content when it fits, between their narrowest and widest when it nearly does, and at their narrowest, each column's longest word, when even that is wider than the text), and a table that overflows scrolls its rows inside a frame that stays put. `MarkdownStyle::table_scroll_bar` gives that table `@opencode/ui`'s native scroll bar in an 8 point strip under the rows, and `MarkdownStyle::wide_fade(0.0)` clips a wide code block at a hard edge. `ScrollBarStyle::native` draws `scrollbar.css`'s bar (a 4 point pill shown only while the pointer is over the area, with no fade), and `ScrollBarStyle::horizontal` runs any scroll bar along a sideways viewport's bottom edge.
