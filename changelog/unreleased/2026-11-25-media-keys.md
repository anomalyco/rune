- **Hardware media transport keys (`Key::Media(MediaKey)`, opt-in `App::media_keys()`).** Added `#[non_exhaustive] pub enum MediaKey` (`PlayPause`, `Play`, `Pause`, `Next`, `Previous`, `Stop`, `FastForward`, `Rewind`), `Key::Media(MediaKey)`, `ChordKey::Media(MediaKey)`, and opt-in builders `App::media_keys()`, `WindowSpec::media_keys()`, `ConfiguredOverlay::media_keys()`, and `Runtime::set_media_keys`/`media_keys` (off by default so apps without it see no new keys and never intercept system media keys on macOS). Maps winit `NamedKey::Media*` (Windows, Linux, web), DOM `KeyboardEvent.key` values in `bridge.js`/`web_key`, Linux Wayland layer-shell XKB `XF86Audio*` keysyms, headless script names, `Chord::parse`, and macOS `NSEventTypeSystemDefined` (subtype 8, `NX_KEYTYPE_*`) while the window is key. Focused text fields ignore `Key::Media` so media keys fall through to `on_key`. Wired into `examples/video-player`.
