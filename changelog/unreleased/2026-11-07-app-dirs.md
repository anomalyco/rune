- **`rune::dirs::AppDirs` names an app's config, data, cache, state and log folders on every
  platform.** macOS uses `~/Library/{Application Support,Caches,Logs}/<id>`, Windows `%APPDATA%\<id>`
  for config and data and `%LOCALAPPDATA%\<id>` (with `Cache` and `Logs` inside) for the rest,
  and other platforms follow XDG. It also finds the home folder (`USERPROFILE` on Windows, where
  `HOME` is usually unset) and Downloads. `AppDirs::from_env` takes the environment as a lookup
  so an app resolves its folders once and passes them down, and `sibling` reuses that lookup for
  a second id. `RUNE_DIRS_ROOT=<root>` moves every folder an app writes, `Prefs` included, under
  `<root>/{config,data,cache,state,logs}/<id>` for tests and isolated runs. `Prefs` on Windows now
  falls back to `<home>\AppData\Roaming` when `APPDATA` is unset.
