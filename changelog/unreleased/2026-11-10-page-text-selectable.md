- **Web pages (`App::web_document`) select their text as any web page does.** Drag across a heading or paragraph and ⌘C copies it, without `El::selectable`. Text inside something that takes the pointer (a press, drag or gesture handler, a button, link, tab or field) still doesn't, so its press keeps working; `El::selectable` text there still selects. `El::unselectable` keeps a subtree's text out, as CSS `user-select: none` does. The static export (`--html`) marks the same text unselectable. Full-window web apps, desktop and iOS are unchanged.
