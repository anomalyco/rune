- Web: files pasted into or dropped on a focused Rune text field (not a password field) reach its `on_input_paste` (or a root `on_paste_content`) as `ClipboardContent::web_files`, up to `MAX_WEB_FILES` `WebFile` handles (name, type, size; no path, nothing read until `WebFile::read` or `WebFile::js_file`), held by the page for as long as the app keeps the `WebFile`. Plain text paste is unchanged. A paste or drop that carried only files or an image no longer pastes empty text into a field that takes neither (one without a hook, password fields included), and a dropped text file is pasted as text only up to 1 MiB.
