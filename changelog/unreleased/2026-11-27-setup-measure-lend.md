- **`AppSpec::setup` and overlay `setup` text measurements use the window's or overlay's `TextSystem`.** `rune::text::measure` and its sibling helpers now lend the runtime's own `TextSystem` while `setup` runs (with `App`-level runtime configuration such as `App::emoji_family` already applied), so fallback fonts and shaped layouts prepared during setup stay warm for the first frame instead of landing in a separate thread-local measurement cache.
