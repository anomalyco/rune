- **A web app feels like a page where a page would behave differently.** Right-click opens the browser's own menu over what a page would have there (the selection, with Copy and a search for it; a link, with Open in new tab and Copy link address; a text field, with Cut, Copy and Paste on the field's own text; text; the page) instead of Chrome's image menu for the canvas, which also showed on top of the app's own; an element's \on_secondary_press\ menu still wins, and Shift+right-click always gives the browser's. A web link takes the pointer while it's over it, so the status bar shows its URL and middle-click and Ctrl+click open it natively. Ctrl+wheel (a touchpad's pinch) zooms the page unless Rune pinches something there. The input method's candidates open at the caret, not in the page's corner. A dropped PNG or text file pastes into the focused field. The semantic mirror sets text in the app's own fonts (shared with the page as \FontFace\s once the first frame is up, from the bytes Rune has), so the browser's Find highlights land on the glyphs; Windows' contrast themes no longer paint the mirror's text over the canvas; printing fits what's on screen to the paper.
