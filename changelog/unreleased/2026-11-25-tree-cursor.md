- **The tree dump (`--tree`, and a hot snapshot's JSON) says where the pointer is and which cursor it shows.** A top-level `pointer` object holds `at` (the point, in view points) and `cursor` (`Runtime::cursor` by its CSS name: `default`, `pointer`, `text`, `col-resize`, `not-allowed`, ...; `none` for `Cursor::Hidden`, `image` for an app's own picture), present once the pointer has been somewhere. The one element the shape is read from (the pressed element while a gesture holds the pointer, else the hit target under it) carries the same name as `cursor`: its own cursor, else the nearest ancestor's, else `default`. A headless run can now check cursors without a window.
