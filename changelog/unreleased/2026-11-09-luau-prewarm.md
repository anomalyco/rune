- **A Luau reload swaps faster.** `Script::prewarm` builds the next VM's base (the Luau state, the prelude, `@rune/ui` and the host's `ScriptOptions::setup`) ahead of a reload, so the swap on the UI thread only loads and runs the script's modules; `Script::watch` prewarms while a save compiles. `Sources::compile_from(&previous)` reuses the bytecode of every module whose source didn't change, and `Script::watch` compiles with it and skips events that leave the files as they were (one save is often several), so a save reloads once and recompiles one file.
