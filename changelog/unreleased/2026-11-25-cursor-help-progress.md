- **`Cursor::Help` and `Cursor::Progress`** (CSS `help` and `progress`): the arrow with a question mark, over something that explains itself when the pointer rests on it, and the arrow with a busy mark, while work is under way and the app still takes input. Windows shows `IDC_HELP` and `IDC_APPSTARTING`, Wayland and X11 the theme's `help` and `progress`, the web the CSS cursors, and macOS AppKit's own help and busy-but-clickable cursors where it has them (the arrow where it does not). `Cursor` is `#[non_exhaustive]`, so an app's `match` on it already has a wildcard arm.
