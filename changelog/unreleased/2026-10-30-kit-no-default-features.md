- **`rune-kit`, `rune-mermaid` and `rune-theme-opencode` no longer turn on Rune's default features.** They depend on `rune` with `default-features = false`, since none of them uses `dbus`, `embedded-fonts`, `ogg-audio` or `svg`. Before, Cargo's feature unification turned all four back on for any app that used one of these crates, so an app that set `default-features = false` on `rune` to leave out symphonia, opuscule, resvg or zbus still built them. An app that depends on `rune` with its defaults is unchanged; an app that reached Rune only through these crates and relied on a default feature now adds `rune` with that feature itself.
