- Linux Wayland window backdrops: added `WindowBackdrop::Blur`, memo-tracked `Cx::window_backdrop_supported(backdrop)`, and headless `Runtime::set_window_backdrop_supported(backdrop, supported)`. On transparent Wayland GPU toplevel windows and overlays (`zwlr_layer_shell_v1` and toplevel fallbacks), Rune binds `ext_background_effect_v1` (version 1, tracking runtime `Capability::Blur` changes with zero background threads) with `org_kde_kwin_blur_manager` (version 1) as fallback when `ext_background_effect_v1` is absent, approximates `sctk-adwaita` rounded bottom corners in surface-local logical `wl_region` coordinates, makes zero blur calls on opaque windows or when left at `WindowBackdrop::None`, and falls back to an opaque theme-matched clear on non-overlay Linux transparent windows whenever blur is unavailable.
