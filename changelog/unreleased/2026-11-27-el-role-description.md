- **`El::role_description` and `El::role_description_static` (ARIA `aria-roledescription`):** added `El::role_description` and `El::role_description_static` wired to AccessKit (`Node::set_role_description`), `Runtime::accessibility_json()` (`"roleDescription"`), the web DOM accessibility mirror and focus proxy (`aria-roledescription` via `"rd"`), and static HTML export (`aria-roledescription`). Ignored on elements with no accessible role and when empty or whitespace-only, following WAI-ARIA 1.2.
