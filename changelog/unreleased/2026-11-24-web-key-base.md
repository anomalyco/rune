- Web: `Tx::key_base()` is now populated from `KeyboardEvent.key` on both canvas (`WindowEvent::KeyboardInput`) and focused text input (`bridge.js` -> `web_key`) paths when unmodified or for shifted letters (lowercased), so non-ASCII chords like German `Ctrl+Ö` (`Command(';')`, `key_base: Some('ö')`) and Russian `Ctrl+М` (`Command('v')`, `key_base: Some('м')`) match logical shortcuts via `Chord::matches_tx` while shifted punctuation, Alt/Option combinations and dead keys stay `None`.
