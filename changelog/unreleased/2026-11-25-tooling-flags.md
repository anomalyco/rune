- Tooling: added `rune::tooling::flags()` (and `Args::flags()`) returning a static `&'static [FlagSpec]` slice (`FlagSpec`, `FlagValue`, both `#[non_exhaustive]`) shared with `Args::parse_split`, so apps that own their CLI via `App::args` can render uniform help and forward Rune flags without drifting; feature-gated flags (`hot`) appear only when enabled, and release builds without `tooling` or `hot` return `&[]`.
