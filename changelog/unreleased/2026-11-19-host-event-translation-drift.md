- **Unified input event translation across desktop windows, overlays, headless runs, and the virtual desktop.** Window-backed overlays now share the desktop window host's wheel, gesture (pinch, rotate, smart magnify), touch (with Windows touch-promotion filtering), secondary/extra mouse button (including macOS Ctrl+click), IME, non-synthetic keyboard (with clipboard paste fallback), zoom-scaled pointer coordinates, monitor scale-change on move, and focus/hide preference and modifier-state resets. Virtual-desktop runs now share the headless driver's `script_input` translation, scaling coordinates and wheel/fling deltas by zoom, handling scripted `Resize` events, releasing pointer capture on blur, and emitting `keys_lost` on hide.
