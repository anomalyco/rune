- Overlays take the same input as windows: the wheel and trackpad scrolling, pinch, rotate and smart magnify, touch, the right and other mouse buttons (and Ctrl+click on macOS), IME composition, and pointer positions under `Cx::zoom`. An overlay's window dropped these. A `--desktop` run also scales scripted pointer, wheel and fling input by the zoom, handles a scripted resize, and releases held keys when its window hides, as a headless run does.
