- Motion: `AnimationStore::play_keyframes` now returns `Option<TrackId>` instead of `TrackId`, returning `None` without panicking, creating a track, or disturbing an existing track when given an empty `Keyframes` (also added `Keyframes::is_empty`); callers that use the returned `TrackId` should handle `None` (for example `if let Some(id) = store.play_keyframes(...)` or `.expect(...)` when the track is known to be non-empty).
