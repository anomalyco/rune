- Elements that are animating out are skipped everywhere a key is looked up: a horizontal `scroll_into_view` no longer scrolls to an exiting row, an exiting element no longer hides the live one with the same key from `active_descendant` and `labelled_by`, and controls inside an exiting parent stop showing hover and press. A pop-up menu anchored by a key such as `slider/knob` also opens when unkeyed wrappers sit between the two, as `Runtime::find` resolves it.
