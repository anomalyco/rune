- Text: `RUNE_SYSTEM_FONTS=off` (or `rune::text::set_system_fonts(false)`) stops every text system from loading system fonts, for `families` slots, `ui-monospace`/`Family::SystemMono` and script, CJK, symbol and emoji fallbacks, so headless `--tree` and `--snap` text metrics depend only on the bundled fonts, `AppSpec::fonts` and `add_font` and match across macOS, Windows and Linux; `ui-monospace` then falls back to the sans slot and a character no registered font has draws as its missing glyph. Default behaviour is unchanged (#2412).
