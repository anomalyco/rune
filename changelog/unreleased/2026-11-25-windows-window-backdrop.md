- Windows 11 system backdrops: added opt-in `WindowBackdrop` (`None`, `Mica`, `MicaAlt`, `Acrylic`) with `App::window_backdrop`, `WindowSpec::window_backdrop`, `ConfiguredOverlay::window_backdrop`, runtime setters `Tx::set_window_backdrop`, `WindowHandle::set_window_backdrop`, and `OverlayHandle::set_window_backdrop`, plus memo-tracked `Cx::window_backdrop()` and `Runtime::set_window_backdrop`. On Windows 11 Build 22621+ transparent DirectComposition hardware-GPU windows and overlays, Rune applies the documented `DWMWA_SYSTEMBACKDROP_TYPE` attribute (and syncs `DWMWA_USE_IMMERSIVE_DARK_MODE` while active), re-applying across recreation, hide/show, maximize/unmaximize, and theme changes, with zero DWM calls when left at default `None` and an opaque theme-matched clear fallback on non-overlay Windows windows where a requested backdrop cannot activate.
