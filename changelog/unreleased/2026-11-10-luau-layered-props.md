- Luau: a node takes a frozen style and a small table of its own props laid over it (`ui.row(ROW, { key = id }, children)`, `ui.text(words, LABEL, { color = ink })`), and only that table is decoded onto a copy of the style's node; `ui.text` fills `{1}`, `{2}`... from the values after its props; `ui.each(items, key, version, build)` memoizes each item of a list; `ui.virtualList` takes `rowVersions`, and with `scrollY = false` lists rows inside a scrolling column under other content, as `El::virtual_rows` now windows against the nearest scroll viewport at any depth. A frozen style's colours are checked once per render.
