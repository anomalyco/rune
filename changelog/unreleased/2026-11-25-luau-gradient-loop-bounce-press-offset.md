- rune-luau: `ui.*` props add `gradient = { colour, ... }` (2 to 16 evenly spread stops, linear at `angle` degrees, default `180`, or radial with `radial` points about `cx`/`cy`, default `0.5`; these shaping props paint nothing without a `gradient`), `loop = "spin:<s>" | "slide:<s>:<dx>:<dy>" | "blink:<s>:<low>"` (`El::looping`; slide offsets are fractions of the node's size), `bounce` (`true` or a bounce in `[0, 1)`, the spring `scale` changes on), `pressOffset = { x?, y? }` (`El::press_offset`), and `hoverTransition` in seconds (a CSS `ease` tween up to 60 s; `0` is instant).
