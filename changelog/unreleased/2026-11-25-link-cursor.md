- **`El::link_cursor(Cursor)`: the pointer's shape over a selectable text's links.** Selectable text shows the I-beam and its links the hand, and nothing an app set could change the hand: `El::selectable` takes the element's cursor for the I-beam, and the link's hand was fixed in `Runtime::cursor`. `link_cursor(Cursor::Default)` now gives a link that reads as plain text the arrow (a web page's `a { cursor: default }`). The hand stays the default, so no app changes until it calls this; text that isn't selectable is unchanged (its links show the element's own `El::cursor`), and so are a text field's links.
