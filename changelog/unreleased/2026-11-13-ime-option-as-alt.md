- **`El::ime_option_as_alt(on)`: on macOS, Option is the Alt key while that caret has the input method.** An app's own editor (a terminal) asks for it beside `El::ime_cursor`; the window then sets winit's `OptionAsAlt::Both`, so Option and a key arrive as that key with `mods.alt` (and `Tx::key_base`) instead of the character the layout composes, which the input method otherwise committed, out of the key handler's reach. Off again when another caret or field takes the input method. Nothing changes elsewhere.
