- **Windows: a window behind another draws its frames on time.** Each window's next frame is one `Redraw` machine (`window::redraw`): a frame it asks for while it paints is asked for at the end of the loop's turn, and on Windows a window whose asked-for paint the system has put off for a frame is painted there by the loop itself (its pending `WM_PAINT` dropped). Windows makes up one window's `WM_PAINT` at a time, the top one first, and winit ends its message pass after each, so a front window that kept asking (inside its paint, or from a timer or a wake) painted every turn and one behind it waited until the front rested: about 1.5 s after a short streamed reply, the whole reply while one streamed. The steady run that keeps a Windows window presenting for a second after a change (`STEADY`) is a `Steady` machine now, and holds only for the focused window. Right-click's window menu opens at the click rather than wherever the pointer is when it opens.
