- **Spellcheck language matching and web dictionary filtering.** Regional BCP 47 tags (such as `en-AU` or `de-AT`) and underscore/case variants (`en_US`) now match available dictionaries sharing the same primary language subtag instead of returning no match, without cross-matching prefix-similar languages (`es` vs `est`). On web, deselecting a previously loaded dictionary with `spell::set_languages` now stops checking text and offering suggestions from it immediately.
