- **Linux Wayland `Cx::decoration_mode`, `Cx::tiled_edges`, `Cx::window_actions` plus X11 `PropertyNotify` wake and Mutter/Ubuntu X11 fixes (updates `vendor/winit.patch`; apps pinning `dev` must update their `[patch.crates-io]` winit rev).** Vendored `winit` now exposes `WindowExtWayland::wayland_wm_state()` reading `xdg_toplevel` / `xdg-decoration` configure state gated by `xdg_toplevel` protocol version (`>= 2` for tiled edges, `>= 5` for `wm_capabilities`, preserving `Unknown`/`None` on older compositors, before the initial configure, and for `close`), wakes on decoration-mode or capability changes without a resize, and exposes `WindowExtX11::take_wm_state_changed()` set by `PropertyNotify` on `_NET_WM_STATE`, `_NET_WM_ALLOWED_ACTIONS`, `_GTK_EDGE_CONSTRAINTS`, and `_NET_FRAME_EXTENTS` so non-resize X11 property changes sync chrome with zero X11 IPC on ordinary redraws.
