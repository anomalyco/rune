- **`El::border_layout` makes a border take room in layout as a CSS border does, a whole device pixel for a 0.5 point one, and Markdown's table rows use it.** The element's padding and content lay out inside its `border` or `border_sides`, each side as wide as it draws, snapped as Chromium snaps a border width (under a device pixel, one; above, whole pixels), so a row with `border-bottom: 0.5px` is 0.8 points taller at 1.25x and a stack of rows ends where a web page's does. Markdown table bodies draw their row rules as such borders (`tbody tr:not(:last-child) td { border-bottom: 0.5px }`) instead of 0.5 point rule elements, so at 1.25x a table no longer ends a device pixel short per few rows. `CompactStyle::set_border` sets layout border widths.
