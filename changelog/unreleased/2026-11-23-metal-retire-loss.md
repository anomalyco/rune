- **macOS: a failed command buffer of Rune's Metal backend is heard lost before its work is done.** The backend retired a command buffer under its lock but set the device's loss after, outside it: another thread could run the failed work's `on_submitted_work_done` callback before the loss showed. The loss is now set in the same lock as the retirement, its callback queued first, and callbacks run in order on one thread at a time.
