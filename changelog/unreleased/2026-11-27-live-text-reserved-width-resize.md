- **`El::live_text` keeps its placeholder's reserved layout size across resizes and memo reuse.** Once a `LiveText` updated a node's text, a subsequent window resize or memo reuse with a different available width measured the latched live string instead of the authored placeholder. `NodeCold` now preserves the authored placeholder (and its single-line measured size when unwrapped) before the first live replacement so layout re-measures keep the reserved box without extra shaping.
