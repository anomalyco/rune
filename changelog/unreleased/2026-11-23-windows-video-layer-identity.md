- Windows video: a seek or pause on a clip's layer no longer freezes the picture while time and sound run on. The decoder closes the clip's layer when the clock stops and makes a new one when it runs again, and Windows often gives the new layer's surface handle the closed one's value; the window kept its visual when the handle value was the same, so it went on showing the closed surface. Each layer now has an id of its own (`LayerSurface`), and the window makes a new visual whenever the id changes.
