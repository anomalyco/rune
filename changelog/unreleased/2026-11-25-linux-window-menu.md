- Linux: a right-click on a bare `.window_drag()` region, or Alt+Space no handler takes, now opens the window manager's window menu, through `xdg_toplevel.show_window_menu` on Wayland and `_GTK_SHOW_WINDOW_MENU` on X11 when the window manager advertises it in `_NET_SUPPORTED` (winit's X11 `show_window_menu` does nothing). Alt+Space now reaches handlers as `Unhandled::WindowMenu` on Linux when the menu is available, as on Windows.
