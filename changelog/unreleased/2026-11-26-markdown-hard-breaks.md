- `rune-kit` `Markdown::hard_breaks(bool)`: opt-in builder (`false` by default, preserving CommonMark) that renders soft line breaks (single newlines in paragraphs, emphasis, links, list items, block quotes, headings and table cells) as line breaks (`'\n'`) while keeping code spans, code blocks, post-image line breaks, incremental streaming parses, separate parse/memo cache entries, and `copy_source(true)` verbatim source copies intact.
