- **rune-kit Markdown: inline code is a left-to-right isolate**, as `:not(pre) > code { direction: ltr; unicode-bidi: isolate }` makes it on a page: code inside Arabic or Hebrew text reads left to right and moves as one, its punctuation staying with it. Copied and plain text leave the isolate marks out with the padding, and code that ends a line or table cell drops its isolate's end with its padding, so streamed text only grows.
