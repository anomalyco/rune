- **`rune::watch_display_queue(pending, dispatch) -> DisplayQueueWatch`: UI-thread dispatch for secondary Wayland `wl_display` event queues (#522).** Apps binding extra Wayland protocols on winit's display (via `WindowHandle::with_raw_display_handle`) can register one or more `DisplayQueueWatch` guards (across multi-window hosts and `.windowless().keep_running()` daemons) instead of running a reader thread. While any watch is active on Wayland, Rune enables winit's wake-on-read flag, dispatches queues whose `pending()` returns `true` on the UI thread in the same turn, catches mid-turn reads with one coalesced wake without polling while idle, and stops and drops every watch strictly before `App::on_display_close` runs. Zero cost when unused, zero `vendor/winit.patch` changes; compiles as an inert no-op on X11, macOS, Windows, and web.
