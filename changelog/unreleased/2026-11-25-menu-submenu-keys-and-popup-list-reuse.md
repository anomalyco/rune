- **`rune-kit` `Menu` / `MenuItem` submenu placement, keys, accessible labels, and `PopupList` rich labels / standalone reuse.** Added `MenuItem::submenu_placement(Placement)` (default `Placement::RightStart`), `MenuItem::submenu_min_width(f32)` (default `160.0`, `0.0` for content width), `MenuItem::key`, `MenuItem::a11y_label`, `Menu::label`, `PopupItem::label_with(El)`, and `PopupList::build_list(&Kit) -> El`, and exposed `role="menu"` containers in the web accessibility mirror so `Menu::label` reaches the DOM mirror too; existing defaults are unchanged.
