- **Every text keeps its lines' own height, as a browser lays out text, instead of rounding it up to whole device pixels.** A 13 point text on a 19.5 point line is 19.5 points tall at any scale, so a column of texts, a list's rows and the boxes around them land where a web page's do instead of gaining up to a pixel per text; Markdown already did this with `El::exact_lines`, which every text now does. `El::rounded_lines` keeps the old rounding for a box that must sit on the pixel grid, and `rune::text::measure` reports the same unrounded heights the runtime lays out (widths still round up to whole points), so a virtual list's estimates match its rows.
