- **`rune::text::compare_names`: names in the order a person reads them, in the interface's language.** It follows the language's alphabet (German ä beside a, Swedish ä after z) with case and width aside, and runs of digits by value (`file2` before `file10`). The OS's own collator decides: Windows' `CompareStringEx` with `SORT_DIGITSASNUMBERS`, and macOS's `CFStringCompareWithOptionsAndLocale`, numeric, as Finder sorts. Linux and the web use a natural order by case-folded characters and digit runs. Rune carries no collation data. Ties fall back to code points, so the order is total.
