- **A handler can send a key and take the window full screen.** `Tx::send_key` delivers a key once the handler is done, as if typed, so a menu the app draws itself can send Ctrl+C (⌘C) and the other Edit keys to the focused field, as AppKit's standard Edit items do. `Tx::toggle_full_screen` takes the window full screen or brings it back: borderless over its display on Windows and Linux, where a custom titlebar's caption buttons hide.
