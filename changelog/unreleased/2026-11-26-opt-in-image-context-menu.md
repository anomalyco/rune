- Added opt-in image context menus via `ImageMenu` (`ImageMenu::new`, `.save_bytes`, `.save_path`, `.file_name`, `.address`), `El::image_menu`, and `Label::{SaveImageAs, CopyImage, CopyImageAddress}`. Right-clicking (or pressing Menu / Shift+F10, long-pressing on touch, or invoking AccessKit `ShowContextMenu`) an opted-in image shows **Save Image As…** (native only; writes original bytes/regular file verbatim off the UI thread so SVG and animated images stay intact; omitted on `wasm32`), **Copy Image** (off-thread PNG encode via `Tx::copy_image_then`, disabled while pending, failed, or over 64 MP, leaving the clipboard untouched and announcing/logging on error), and **Copy Image Address** (valid `http:`/`https:`/`mailto:` URLs). Composes with enclosing `El::href` links (link items, separator, image items) and `rune_kit::Markdown::image_frame` with zero cost on plain image elements.
