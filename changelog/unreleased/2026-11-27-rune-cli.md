- **Added `rune-cli` (`rune` binary) for project scaffolding, pin checks, diagnostics, and cross-platform dev/hot reload** (`crates/rune-cli`): `rune new <name>` generates an app pinned to Rune's `dev` rev and `[patch.crates-io]` list (or `--path` for a local checkout) with `hot = ["rune/hot"]`, `[profile.rune-hot]`, `rune.toml`, and a live-patchable `src/view.rs`; `rune dev` runs guarded `dx` 0.7.10 hot patching with the AST syntax-contract guard embedded in Rust (no Bash/Python required) and falls back automatically to cross-platform watch-and-restart `cargo run` when `dx` is absent or by default on Windows; `rune check` verifies Rune git/`[patch.crates-io]`/`Cargo.lock` pins and runs `cargo check`; `rune doctor` checks toolchain, platform prerequisites, `dx` status, and project config.
