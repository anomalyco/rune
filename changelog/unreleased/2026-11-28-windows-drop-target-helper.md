- **Windows: keep drag images visible over Rune windows via `IDropTargetHelper`, and add drop descriptions and copy/move/link drop feedback.** Rune's Win32 OLE drop target now lazily creates `CLSID_DragDropHelper` (`IDropTargetHelper`) and forwards `DragEnter`, `DragOver`, `DragLeave`, and `Drop`, while `drag_out` enables `DSH_ALLOWDROPDESCRIPTIONTEXT` on `IDragSourceHelper2` so drop description labels render over custom drag bitmaps too. New `El::drop_feedback`, `DropFeedback`, `DropDescription`, `DropDescriptionKind`, `DropInfo`, `DragOperations`, and `Tx::{drag_mods,drag_operations,drop_operation,set_drop_operation,set_drop_description}` let drop targets choose Copy/Move/Link/None and set Windows `CFSTR_DROPDESCRIPTION` labels (defaulting unchanged to copy-only for existing `El::on_drop_files` targets).
