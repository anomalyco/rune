- **A hover group across rows, and tooltips above.** `El::hover_group_shared(key)` is a `hover_group` shared by every element with the same key, so the pointer over any of them hovers them all: a reply's text and its footer in separate rows of a virtual list light together. `El::help_above` shows an element's tooltip above it, 4 points clear, and below only when there's no room, as a web page's `placement="top"` tooltip.
