- **Windows: a launch hands off only to an instance that answers.** The running instance acknowledges each launch on its pipe (accepted, or quitting: then the launch claims the instance itself once the old one lets go), and a launch whose instance doesn't answer in time, or whose instance is ending (it has an exit code while its threads and pipe linger for seconds after Task Manager's End task), passes that name over for the next and opens its window. A launch right after a kill used to end at once with no window.
