- **Windows: a window's GPU adapter is picked from DXGI's list, and only that adapter goes to wgpu.** wgpu's `enumerate_adapters` and `request_adapter` made a D3D12 device on every adapter to describe it (the discrete GPU and WARP included), which woke a hybrid laptop's discrete GPU and loaded its driver for a window drawn on the integrated one. Rune now makes the same choice (`WGPU_ADAPTER_NAME`, `WGPU_POWER_PREF`, the GPU driving the primary display, else the lowest-power one) from DXGI's descriptions and exposes the one adapter through a function added to a vendored wgpu-hal (`vendor/wgpu-hal`, `dx12::Instance::expose_adapter`, re-made by `scripts/vendor-wgpu-hal.sh`). On a two-GPU laptop: adapter pick 1,065,377 → 53,987 µs p50, first frame 1,217,012 → 205,171 µs, and the process ends 774,208 → 112,274 µs after `main` returns. **Apps that build Rune must add `wgpu-hal = { git = "https://github.com/anomalyco/rune", rev = "<the Rune rev they pin>" }` under `[patch.crates-io]`**, since a dependency's patches don't apply to the workspace that uses it; without it they build as before, with the old pick.
