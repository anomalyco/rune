- **`rune-i18n` localizes an app from JSON catalogs.** A build script runs `rune_i18n::codegen::generate` (feature `codegen`) over a folder of `<layer>/<locale>.json` files and gets `KEYS`, `PLURALS` and a `CATALOG` of one embedded text blob and span table per locale; `Key::named` and `PluralKey::named` are `const fn`s, so a mistyped key fails the build. `I18n` keeps the current locale in an atomic: `text` is a slice lookup that falls back to the source locale, `set_locale` switches every later lookup, and `plural`, `integer`, `decimal` and `list` use ICU4X's CLDR plural rules, digits, grouping and conjunctions. `render` and `parts` fill `{{name}}` placeholders; `system_languages` reads the OS's preferred languages (Windows, macOS, iOS, web, POSIX) and `negotiate` matches them to supported locales by language and likely script.
