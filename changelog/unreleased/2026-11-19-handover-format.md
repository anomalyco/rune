- **Windows: the first GPU frame after a CPU start draws with a pipeline built for the window's format.** With the GPU warmed before the window existed and `srgb_blend` off, the handover's warm-up frame drew a `Bgra8Unorm` pipeline into a `Bgra8UnormSrgb` target, which the device rejects. The renderer is now set to the target's format and blend mode first, a blend switch made during the handover is applied before the first GPU frame, and a video in that frame has its pipeline built off the UI thread as on every later frame.
