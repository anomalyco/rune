- **A clicked Windows toast can start the app after it quit.** `Identity::activation(scheme)` makes toasts protocol-activated: a click opens `<scheme>://notification/<id>?<user info>`, which `register` points at the running executable for the user, so a toast left in the notification center starts the app, or with `rune::single_instance` reaches the running one. `click_from_url(url)` turns the app's own notification links back into the `Click` (`rune::App::on_open_url` receives them). Without a scheme a click reaches the posting process while it runs, as before.
