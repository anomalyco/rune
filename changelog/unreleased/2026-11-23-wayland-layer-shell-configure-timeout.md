- **Wayland: a layer-shell overlay that never receives an initial configure no longer freezes the app.** `LayerSurface::new` now bounds its initial configure wait to 2 seconds using `prepare_read` and `poll` instead of an unbounded `blocking_dispatch`, logging and returning `None` on timeout so the overlay fails cleanly as unavailable (or falls back to XWayland) without hanging the event loop.
