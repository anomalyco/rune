- **Text: ClearType and Windfoil RGB no longer freeze the window for a minute.** Their subpixel pipeline (the uber shader blending by a second output) was compiled from WGSL by FXC on the UI thread the first frame it was wanted: about 60 s of a black, unresponsive window spinning a core (80 s offline). Rune now ships its bytecode beside the uber shader's (`uber.vs-dual.dxbc`, `uber.fs-dual.dxbc`, made by `regen_dxbc` and gated by the same WGSL and layout hashes), so it builds at once on DX12. Where the bytecode can't be used, it compiles on a thread of its own while subpixel text draws grayscale on both painters, and the window is woken when it's ready. Subpixel text now turns on when the pipeline is built, not when the device merely has dual-source blending, so the CPU and GPU frames switch together (hand-over drift 17,846 -> 40 px with the bytecode off).
