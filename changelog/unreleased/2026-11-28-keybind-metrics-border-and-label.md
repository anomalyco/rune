- `rune-kit`: `KeybindMetrics` gains `border_width`, `border_color` and `label` so themes can draw a bordered keycap rim (on `KeybindVariant::Neutral`; `Ghost` stays unbordered) and style the keycap label's typography. Defaults (`border_width: 0.0`, `border_color: k.c.border_base`, `label: TextStyle { line_height: 11.0, ..k.ty.small_medium }`) leave existing keybinds unchanged; code writing `KeybindMetrics { .. }` without `..KeybindMetrics::kit(&k)` needs the new fields.
