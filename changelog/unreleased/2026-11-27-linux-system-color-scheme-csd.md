- **Linux `ColorScheme::System` windows theme their native frame from Rune's resolved desktop scheme instead of `dbus-send`.** On Linux, `ColorScheme::System` windows now pass an explicit `Theme::Dark` or `Theme::Light` resolved from Rune's XDG Settings portal (`zbus`) and off-UI-thread GSettings/GTK/`kdeglobals` fallback to winit at creation and on live desktop theme changes, rather than passing `None` and letting `sctk-adwaita` spawn `dbus-send` (which drew a light CSD headerbar on dark desktops without `dbus-tools`, such as stock Fedora Silverblue). `Cx::system_dark()` continues to track live desktop preference changes on Linux independently of the window's applied CSD theme.
