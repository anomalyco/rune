- **The OpenCode theme ships Desktop's file icons and its whole icon catalog.** `file_icons::file` and `file_icons::folder` pick `@opencode/ui`'s colour FileIcon badge for a path as its `chooseIconName` does (313 badges and folder icons). `tree_icons::file` picks the monochrome `@pierre/trees` icon that Desktop's file trees draw, and gives the colour of the file type for a selected row. `tree_icons::style` and `tree_icons::item` draw Desktop's file tree rows. `icons` now holds every catalog icon (170, with `icons::ALL`), so `OUTLINE_HEXAGONAL_WARNING`, `OUTLINE_SQUARE_ARROW` and `CHEVRON_GRABBER_VERTICAL` are available. `OUTLINE_COPY` follows the catalog's new artwork, and `SUBAGENT`, which the catalog dropped, is gone. The kit gallery shows them in the `components-file-icon--*`, `ui-icon--gallery`, `rune-*-icon--catalog` and `rune-tree--files` scenes.
