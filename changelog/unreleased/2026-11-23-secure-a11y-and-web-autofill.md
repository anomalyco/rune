- Secure fields and secure text no longer expose `TextRun` children, character metrics, text selections, `SetTextSelection`, `--tree` caret geometry, `--html` export content, web mirror descendants, unredacted `on_key` event logs, or `TextEdit` `Debug` selection offsets; on web, password inputs now set `autocomplete="current-password"` and replace the field's whole text on browser or password-manager autofill instead of appending to typed text.
