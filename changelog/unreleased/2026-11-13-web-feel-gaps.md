- Copying selected text puts HTML on the clipboard beside the plain text, as a browser copies a page's selection: headings, paragraphs, nested lists, tables, code blocks, bold, italic, inline code, strikes and links (`Runtime::copy_html`). Pasted into a document or a mail it keeps its formatting. Every platform.
- Web: tables reach screen readers. The page's mirror gives a table's parts their ARIA roles (`table`, `row`, `cell`, `columnheader`, `rowheader`), as the static export does.
- Web: pop-up menus (`Tx::popup_menu`, a field's menu, selected text's Copy) open as the page's own elements (`role="menu"`, keyboard, pointer and screen reader use, light or dark as the window draws), where before a page answered every menu `None`. `popup_menu_supported` still says false, so an app that draws its own menus keeps them.
- Web: spell checking. A page checks with Hunspell dictionaries it fetches from `spell/<tag>.aff` and `.dic` the first time a field checks (`spell::set_web_dictionaries`), marks misspelled words, and a right-click on one opens Rune's field menu with the suggestions; anywhere else in a field it stays the browser's menu.
- Web: a contrast theme (CSS `forced-colors`) reaches `Cx::system_contrast` with the browser's system colours, as Windows' does natively.
