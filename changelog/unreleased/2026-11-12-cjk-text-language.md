- **Text: Han characters take the forms and font of the language their text is written in, and CJK fallbacks load their own weights on Windows.** A text with kana now shapes and falls back as Japanese, one with Hangul as Korean and one with Bopomofo as Traditional Chinese, whatever `set_language` chose, so a Japanese sentence in an English interface draws `設定を開く` in one Japanese font rather than `設定` in a Chinese one beside `を開く` in a Japanese one; other text keeps the interface language. Han text missing from the CJK fonts loaded so far (Simplified Chinese in a Japanese font) asks Windows for a font that has it, once per character, instead of drawing an empty box, and every CJK fallback is ordered again for each language as more load, so a Japanese font loaded after a Chinese one still comes first for Japanese text. On Windows CJK fallbacks and the fonts other scripts fall back to bring their whole family's files (`malgunbd.ttf` beside `malgun.ttf`, Yu Gothic's four weights), so bold CJK, Ethiopic or Khmer text draws in the font's own weight instead of an emboldened regular.
