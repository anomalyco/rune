- **rune-luau: a `cursor` prop on `ui.*` nodes**, by CSS name (`default`, `pointer`, `text`, `grab`, `grabbing`, `not-allowed`, `move`, `col-resize`, `row-resize`, `ew-resize`, `ns-resize`, `nwse-resize`, `nesw-resize`, `crosshair`, `cell`, `zoom-in`, `zoom-out`): the pointer's shape over the node and over what is inside it that sets none (`El::cursor`). A script could not set one, so everything it drew showed the arrow, and only a text field the I-beam. An unknown name is a render error. Nothing changes for a script that doesn't use it.
