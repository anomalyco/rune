- **`Cx::system_text_scale() -> f32` reports the system text-size preference** (`1.0` by default; Windows Settings > Accessibility > Text size via `TextScaleFactor` / `UISettings::TextScaleFactorChanged`, iOS Dynamic Type relative to 17 pt `Large` body text via `UIContentSizeCategoryDidChangeNotification`, Linux `org.gnome.desktop.interface` `text-scaling-factor` via the XDG Settings portal and off-UI-thread GSettings fallback, and the browser's root `font-size` / `16px` watched with a `10rem` `ResizeObserver` probe on web; `1.0` on macOS). A change re-runs the view and its memos. `Runtime::set_system_text_scale` / `Runtime::system_text_scale` and the `RUNE_TEXT_SCALE` capture preset override it in tests and headless runs.
