- **Drag-out snapshots: no bright halos on `*Srgb` targets.** `drag_out::snapshot` now shares `render::surface_alpha::straight_alpha` to decode, un-premultiply in linear light and re-encode when reading back `*Srgb` render targets, keeping direct byte division for `srgb_blend` non-sRGB targets.
- **Virtual desktop: linear-light translucent backdrops.** `--desktop` backdrop loading now premultiplies translucent pixels in linear light rather than in encoded sRGB bytes.
- **Windows handover: target format, blend-switch and video-surface parity.** The background GPU thread now configures pre-warmed renderers for the window's target format and `srgb_blend` mode before drawing `warm_frame`, `gpu_ready` and `gpu_draws_same_frame` reconcile `srgb_blend` switches through `reblend_core`, and `gpu_draws_same_frame` starts async native-surface pipeline compilation with `build_surfaces`.
- **CPU boot: matches GPU backdrop blur cap and scissor-clip layer flattening.** `render::cpu_boot` now caps backdrop blurs at `MAX_BACKDROP_BLURS` and flattens integer-aligned square-clipped layers using the GPU planner's shared `is_scissor_clip` predicate, clipping flattened children's bounds, damage hashes and scroll checks to the active scissor.
- **Reference oracle (`rune-ref`) and glyph atlas uploads.** `rune-ref` now blends `PlusLighter` children additively inside linear layer buffers, saturates before source-over composition, preserves negative (linear) fade origins and non-layer rounded clips (`fade[3]`), and validates continuous-corner primitives; `Renderer::prepare` now grows the first glyph atlas texture to fit explicit `Atlas::dirty` rows.
