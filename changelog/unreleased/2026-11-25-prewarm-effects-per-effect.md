- Renderer: effect-pipeline warming is opt-in per effect. `App::prewarm_effects`, `WindowSpec::prewarm_effects` and `Renderer::set_prewarm_effects` take a `PrewarmEffects` set (`ISOLATION`, `PLUS_LIGHTER`, `LAYER_BLUR`, `BACKDROP_BLUR`; `true` still names all four, the default stays none) and `Renderer::prewarm_effects()` returns the set instead of a `bool`, so an app that draws only `El::backdrop_blur` no longer compiles the `PlusLighter`, layer-blur and isolation pipelines at every launch. The worker now waits until the window has drawn no frame for 300 ms (5 s at most) before it compiles, runs at the utility QoS class on Apple systems as well as below normal on Windows, hands each effect over as soon as it is built, and stops between backdrop blur's pipelines when cancelled; a renderer dropped while its worker rests no longer waits for a compile. A frame that draws a named effect before the worker is done never compiles it twice: it compiles it itself only if the worker has not begun it (the worker skips it), and otherwise waits for the rest of the worker's compile with its priority lent to the worker.
