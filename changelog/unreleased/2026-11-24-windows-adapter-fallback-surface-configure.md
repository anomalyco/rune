- GPU adapter fallback: when a picked adapter creates a device but its surface configuration is refused on a live device (such as a Windows VM whose D3D12 driver returns `E_NOTIMPL` for `CreateSwapChainForComposition`), Rune now walks the remaining adapters through an explicit fallback state machine (remaining hardware adapters first, then software/WARP) and logs which adapter draws. Transient out-of-memory errors, lost devices, and adapters explicitly named via `WGPU_ADAPTER_NAME` never fall back to another adapter, and a machine whose first adapter works enumerates no extra adapters.
