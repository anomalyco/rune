- Web: `PopupMenu::style(PopupMenuStyle)` sets a pop-up menu's colours (background, text, muted, separator, highlight), font family, size and line height, padding and corner radii from the app's palette; unset values keep the built-in light/dark defaults, keyboard, pointer and screen-reader behaviour is unchanged, and native macOS and Windows menus ignore it. With a style set, `--tree`'s `popupMenu` carries the top menu's style as `style`.
