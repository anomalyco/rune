- **On the web, Rune watches its GPU device.** The first uncaptured WebGPU error is logged with the adapter it happened on (vendor, architecture, texture limit) and each different error once after it, up to five, instead of the browser logging the same error every frame until it stops logging. A lost device ends the app with a message to reload instead of drawing into it every frame. The errors are read from the JS device, not through wgpu, whose conversion panics on a `GPUInternalError`.
