- Rich text (`rune-text`): widened `Ink`, layout-span ordinals, `SYNTHETIC_BOLD` (`0x8000_0000`), and `GlyphCache`'s per-run `face` index from `u16` to `u32`, so layouts with 32,768 or more layout-affecting spans no longer collide with the synthetic-bold flag or overflow at 65,536, and glyph cache entries with 65,536 or more glyph runs no longer hit a `u16::MAX` sentinel or wrap to run 0.
