- **Text: colour emoji draw their COLR v1 gradients, emoji by default draw as emoji, and Backspace deletes as browsers do.** A COLR v1 glyph (Windows 11's Segoe UI Emoji, the COLR v1 Noto Color Emoji many Linux distributions ship) is painted from its paint graph (gradients, transforms, clips, layers and their blend modes) at its pixel size, rather than as COLR v0's flat layers or, for a v1-only font, not at all. A character that is an emoji by default (`Emoji_Presentation`: ✅ ⚡ 🔥) takes the colour emoji font as one with `U+FE0F` does, unless `U+FE0E` asks for text. Backspace deletes one code point (an accent, a Thai or Indic vowel sign, a jamo), as Chromium's `BackspaceStateMachine` does, and an emoji sequence (skin tone, keycap, flag, tag sequence, ZWJ sequence, variation selector) or a CR LF whole; before, it deleted whole grapheme clusters, so `हिन्दी` lost `न्दी` at once.
