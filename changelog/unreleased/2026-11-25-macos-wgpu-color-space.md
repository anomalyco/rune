- **macOS: colour-manage wgpu windows and overlay panels as sRGB by default, with `MacColorSpace` opt-out.** `configure_native` now sets `NSWindow.colorSpace` to `NSColorSpace.sRGBColorSpace` for `MacColorSpace::Srgb` (the default on `MacWindowOptions`, matching AppKit windows, browsers, Windows DXGI, Linux Vulkan, and Rune's native Metal backend on wide-gamut displays), covering both ordinary windows and overlay panels even when `wgpu-hal` clears `CAMetalLayer.colorspace` on configure. Apps that want raw display-native values can opt out with `MacWindowOptions::default().color_space(MacColorSpace::Unmanaged)`, which clears `NSWindow.colorSpace` and `CAMetalLayer.colorspace` to `nil`; `MetalSurface::configure` now preserves `CAMetalLayer.colorspace` across `setPixelFormat` so resizes and sRGB-blend switches keep both `Srgb` and `Unmanaged` intact.
