- **`--html out.html` writes a web app's static first frame.** It lays the app out without a GPU, lands entrance motion and writes the scene as HTML and CSS (flexbox, paint, text, links, images, shapes as SVG); `--html-widths 360,640,1000` folds several widths into `@media` rules and `--html-template` fills `<!-- rune:css -->` and `<!-- rune:body -->` in your page. When Rune's first frame is on screen a `web_document` app removes the exported elements, keeping the reader's place, and the canvas dispatches a bubbling `runepresent` event.
