- Linux/Wayland: bind all of an app's global shortcuts in one xdg-desktop-portal `GlobalShortcuts` session instead of one session per shortcut, using stable canonical portal ids by default and adding `App::global_shortcut_named` and `AppHandle::register_shortcut_named` for custom stable ids and user-facing descriptions. Startup shortcuts now bind together in a single `BindShortcuts` call so GNOME and KDE ask for consent once and remember the set across launches; adding or removing a shortcut at runtime closes the session and rebinds the new full set in a fresh session (or closes the session without rebinding when removing the last shortcut).
