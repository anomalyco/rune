- **Text on Linux: unsmoothed text takes Linux Chromium's text gamma, not Windows'.** With `FontSmoothing::Off` on Linux (and in a browser on Linux) glyph coverage follows the curve Skia draws there (`SK_GAMMA_EXPONENT=1.2`, `SK_GAMMA_CONTRAST=0.2`), so light text on a dark page draws 7-14% lighter than before, as Linux Chromium does. Windows, a browser on Windows and macOS are unchanged.
