- **The native Metal backend sets up as fast as wgpu.** Its adapter lists the Mac's GPUs with `MTLCopyAllDevices`, as wgpu-hal does, instead of `MTLCreateSystemDefaultDevice`, which connects to the window server to find the main display's GPU. A headless run's GPU setup (adapter, device, renderer and offscreen target) takes 7.5 ms instead of 16.1 (wgpu: 7.6), and a launch's `prewarm_gpu` thread finishes about 8 ms sooner. On a Mac with two GPUs the backend now picks the integrated one unless asked for `HighPerformance`, as wgpu does, and `enumerate_adapters` lists every GPU.
