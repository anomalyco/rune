- `El::press_on_down` runs a menu button's `on_press` as a mouse's primary button goes down, and its release runs nothing (the web's Kobalte `Menu.Trigger` opens on `pointerdown`); a key, a screen reader's Invoke and a finger's tap still run it on the click. `rune-luau` takes it as `menuTrigger = true` on a node with `onPress`, and on a host node whose builder wires `onPress` with `Host::on_press`; a script without it is unchanged.
