- **`rune-perf` writes nothing in a run with no slow frame or incident, and wakes nothing while the app is idle.** Its thread no longer checks memory on a 2-second timer: it checks as frames arrive, at most every 2 seconds. Slow-frame lines, memory lines and incident files are kept in memory and written once 2 seconds pass with no new finding, and at shutdown, so a burst of slow frames (typing in a slow build) is one write after it, not a write per frame. Memory lines are written only beside a finding, and `perf.json` only beside incidents or at shutdown after the run wrote something.
