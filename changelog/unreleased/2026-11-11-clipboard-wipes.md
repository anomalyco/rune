On X11 another app's copy of the same text is told apart by the clipboard's owner, and on Wayland by the password hint Rune's copies carry; both used to be wiped. A wipe the clipboard refuses, or a clipboard that can't be read for a moment, keeps the secret held and its delay running (the wipe is tried again a watch later) where it used to be reported `Cleared` or `Replaced` and forgotten. Windows checks and wipes with the clipboard open and X11 with the server grabbed, so another app's copy can't land in between; macOS rereads the change count right before the wipe and takes it from the write itself.
