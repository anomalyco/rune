- **rune-luau: Luau's native code generation is the opt-in `native-code` feature; scripts run in the interpreter by default.** mlua's `luau-jit` made a code generator in every VM as it started, and each took a 4 MiB committed code block for its entry thunks whether a `--!native` module ever loaded or not: OpenCode's 21 plugin VMs held 88 MB of commit this way with no native module among them. An app that wants `--!native` modules compiled turns `native-code` on for its Windows and Linux builds.
