- **`set_app_icon` sets the window icon on Linux.** It takes a PNG or JPEG (best square and 256 px or more), and each window opened after the call carries it: on Wayland through `xdg-toplevel-icon-v1` where the compositor has it (KWin, Labwc, Muffin), on X11 as `_NET_WM_ICON`. KWin showed its generic Wayland icon in the title bar, Alt+Tab and the Overview whenever no desktop entry was named after the app id (an AppImage integrator's renamed entry, a binary run from `target/`). Compositors without the protocol keep using the desktop entry. Call it before `run`. A file that isn't an image now fails on Linux as it does on macOS and Windows.
