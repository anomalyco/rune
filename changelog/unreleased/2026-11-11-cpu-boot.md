- **CPU renderer:** `render::cpu_boot` draws a frame's instances, glyph masks and images on the CPU into a `Bgra8` buffer the bytes the GPU writes for them (8-bit sRGB blending with the GPU's rounding, every instance kind, layers, backdrop blurs, glyphs from masks or outlines), across threads in 64×32 tiles, so a window can show its first frame and stay live before any GPU device exists. `CpuPainter` keeps one buffer and repaints only the tiles whose inputs changed, returning the dirty rectangles; `fill_masks` fills Windfoil's queued masks on the CPU (the GPU then samples those texels); `drift` counts the pixels a GPU frame changed at a hand-over; headless `--cpu-boot DIR` paints every frame this way and writes the draw data, both frames and per-frame timings.
