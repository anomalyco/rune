- **Failing to create an app's first window now ends `run`/`try_run` with the error instead of leaving an invisible process.** When no initial window can be created (such as no GPU adapter or a refused surface) and the app did not opt into `App::keep_running()` or `App::windowless()`, `App::try_run`, `try_run_windows_with` and `try_run_windows_with_args` return `Err(...)` and `run` prints the error to stderr and exits 1. Tray apps, `windowless()` apps, `keep_running()` apps and windows that already opened once keep the previous behaviour: the error is logged, recorded in `AppHandle::window_error()`, and a later `open()` / `show()` retries.
