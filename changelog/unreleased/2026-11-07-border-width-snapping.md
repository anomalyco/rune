- **Borders and outlines snap their width to device pixels, as Chromium snaps CSS border and outline widths.** A `border` or `outline` thinner than a device pixel draws one whole pixel, and a wider one floors to whole pixels; an outline's offset snaps the same way. A 0.5 pt border was a faint 0.5, 0.625 or 0.75 coverage line at 1×, 1.25× and 1.5×, and a 1 pt border bled half a pixel at 1.5×; both are now the one crisp pixel Chromium draws. Scales that land on whole pixels (0.5 pt and 1 pt at 2×) draw as before. For a ring at its exact fractional width, as CSS `box-shadow: inset 0 0 0 0.5px` draws, use an inset `box_shadow` with that spread: Kit's Outline and Loading buttons and `MarkdownStyle::table_frame`'s ring now do, as OpenCode's CSS draws them.
