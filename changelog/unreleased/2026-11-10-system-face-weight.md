- **On Windows, text in a system font draws in the face Chromium picks for its weight.** Chromium finds a system face through DirectWrite, which takes the nearest weight (of two as near, the one further from 400), where CSS matching tries heavier faces first above 500. Han text at weight 530 now draws in Microsoft YaHei, not Microsoft YaHei Bold, and kana in Yu Gothic Medium, not Yu Gothic Bold. Text that falls back to a system face shapes again with the weight of the face DirectWrite picks (`text::system_weight`).
