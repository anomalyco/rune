- **File drops: state-aware `El::accepts_drag`, `Tx::drag_paths`, and passive ancestor observers `El::on_drop_hover_within` / `El::on_drop_move_within`.** `El::accepts_drag(|s: &S, paths| ..)` lets a drop target accept or refuse a whole drag using app state and every dragged path together; `Tx::drag_paths()` exposes all dragged paths during drop hover, move, drop and reject callbacks; and `El::on_drop_hover_within` / `El::on_drop_move_within` let ancestors passively follow a drag across child drop targets without stealing drops while keeping stationary drags idle.
