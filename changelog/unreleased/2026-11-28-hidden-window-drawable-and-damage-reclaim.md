- **Hidden macOS windows and overlays release idle drawables and retained damage textures.** When a non-launcher window or overlay hides on macOS, Rune shrinks its `CAMetalLayer`'s `drawableSize` to `1×1` so Core Animation frees unused full-size drawables from the layer's pool, and restores the configured pixel size before the next show or draw. Out-of-sight rest (`RestEvent::Unseen`) also drops the renderer's full-window retained partial-damage texture across all native platforms, recreating it cleanly on wake, and deferred overlay retirement trims staging uploads once in-flight frames finish.
