- **Linux spellcheck uses installed system Hunspell dictionaries via `spellbook` (default-on `hunspell` feature).** `El::spellcheck`, `El::on_spellcheck`, `El::on_spellcheck_languages`, and `rune::spell` now discover `<tag>.aff`/`<tag>.dic` pairs from `DICPATH`, `$XDG_DATA_HOME/hunspell` (`~/.local/share/hunspell`), `$XDG_DATA_DIRS/*/hunspell`, `/usr/local/share/hunspell`, `/usr/share/hunspell`, `/usr/share/myspell/dicts`, and `/usr/share/myspell`, resolve default languages from POSIX locale variables (`LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG`), decode UTF-8/ISO-8859-1/ISO-8859-15 dictionaries, and run scanning, parsing, and word checks off the UI thread. Disable the default-on `hunspell` Cargo feature (`default-features = false`) to omit the MPL-2.0 `spellbook` dependency on Linux and fall back to a no-op; `wasm32` keeps `rune-spell/hunspell` enabled unconditionally.
