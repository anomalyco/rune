- Web: `ImageCache::url`, `ImageCache::file`, and `ImageCache::load` now match the raster image formats Google Chrome decodes in every browser by adding pre-decode header validation for JPEG XL (bare codestream and container) and bounded AVIF sequences (`avis`, showing the first frame), while continuing to refuse formats Chrome does not decode (TIFF, HEIC/HEIF, JPEG 2000, etc.). Native AVIF decoding still rejects `avis`.
