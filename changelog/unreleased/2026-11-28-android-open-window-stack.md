- Android: `rune::open_window`, `App::window`, and `run_windows` now present extra windows as a full-screen in-activity page stack over one shared `ANativeWindow` surface; `WindowHandle` routes `open`/`show`/`hide`/`focus`/`close` to the stack, and Back delivers `Key::Escape` first (staying when consumed), then consults `on_close_request` before popping and running `on_close` (or letting the activity go back on the root window).
