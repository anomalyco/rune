- Linux: the first window no longer waits for the XDG desktop portal before its first frame. The portal is asked when the event loop is made, and `rune::last_appearance(last, keep)` (with `rune::Appearance`) gives Rune the light or dark and reduced motion the app's last run saw: the first frame draws with them, the portal's answer redraws only when it differs, and `keep` gets each new answer to save. Does nothing on other platforms.
