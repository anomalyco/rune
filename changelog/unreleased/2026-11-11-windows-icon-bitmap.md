- **Windows: a window's icon from the exe's resources loads without WIC.** `set_app_icon_resource` asks for the big icon at 128 px, the largest size an icon resource keeps as a bitmap, instead of 256 px, whose PNG image made `LoadImageW` load `WindowsCodecs.dll` and `IconCodecService.dll` (about 3,300 µs to load them alone, on a Windows laptop) and decode it on the UI thread before the first frame.
