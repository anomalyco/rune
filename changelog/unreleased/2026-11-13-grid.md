- **`rune::grid`: a terminal's screen as one element.** `grid(cols, cell_w, cell_h, rows)` paints rows of `GridRow` (a styled line, cells pinned to their columns, background and selection runs, a vector layer) with the text path's layouts, atlas masks and pixel snapping, so it draws the same pixels, on the GPU and the CPU painter, as the `rich` line, `text` per wide cell, fills and `canvas` per row it replaces (0 pixels differ on 32 terminal screens at 1x-2x in both themes). A row is shaped once while the app hands back the same `Rc<GridRow>`, and draws its last frame's instances again while nothing it depends on changed (`TextSystem::emit_key`). Accessibility reads it as a terminal with a text line per row and each character's place. 200x60, headless, thread CPU per frame p50: full redraw 62,508 to 2,461 µs, one row changed 9,505 to 402 µs, nothing changed 8,030 to 302 µs.
