- **A streaming Mermaid diagram only grows.** `render_streaming` now lays out each build held to the build one line shorter: a node never moves back a rank, keeps its order beside the nodes it was laid out with, stays where it was along its rank unless something new needs the room and then only moves on, and no gap between ranks narrows, so the diagram never gets shorter or narrower mid-stream (a flowchart whose fifth line pulled a node a rank further used to go 119, 90, 119, 156 pt tall). Nodes are held by id, so one turning into a subgraph doesn't shift the rest. New `render_streamed` lays out the finished source exactly as `render_with_hover` does, so the diagram settles there in one glide; Markdown uses it once a fence closes in a reply that is still streaming.
