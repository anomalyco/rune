- **`rune::url_schemes(["myapp"])` names the URL schemes an app registered for itself, so on Windows and Linux only launch arguments on them are links for `App::on_open_url`.** Until it is called every `scheme://…` argument is still a link, which also takes a flag's value for one: `myapp --server http://localhost:4096` handed `http://localhost:4096` to the hook, and with `rune::single_instance` a later launch with such a flag did not reopen the app, since only a launch without links does. Call it first thing in `main`, before `single_instance`. Schemes compare without case; macOS already hands an app only links on the schemes its bundle declares, so there it does nothing.
