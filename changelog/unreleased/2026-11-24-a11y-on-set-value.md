- Accessibility: added `El::on_set_value` so range controls receive AccessKit numeric `SetValue` targets directly (clamped to `range_value` bounds when finite and ordered, with or without `range_step`), matching how Chrome sets `<input type="range">` directly to the requested value. Controls with only `on_step` now replace earlier queued accessibility steps on `SetValue` so repeated requests before a frame do not add up, and `rune-kit`'s split-pane resize grip now uses `on_set_value`.
