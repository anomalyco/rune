- Audio (`AudioOutput`): added cross-platform streaming PCM output API (`AudioOutput`, `AudioOutputSpec`, `SampleFormat::I16`/`F32`, `AudioBackend`, `AudioOutputState`, `AudioEvent`, `AudioPosition`, `AudioOutputError`, `AudioPushError`, re-exported from `rune_media` and `rune`) backed by a pure state machine (`rune_core::machine`), a bounded zero-allocation pre-gain ring buffer (2.5 s default, clamped 100 ms..=10 s and capped at 16 MiB) with ~10 ms post-buffer volume/mute scaling and pause tail rewind, discrete `WakerSlot` event delivery, a cross-platform `AudioOutput::open_silent` virtual sink (including `wasm32`), and an internal `SinkDevice` seam for OS backends (`AudioOutput::open` returns `AudioOutputError::Unsupported` until platform backends land).
