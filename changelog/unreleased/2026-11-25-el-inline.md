- **`El::inline(at, slot, child)`**: static `text` and `rich` elements can now place interactive child `El` subtrees inside in-flow `InlineBox` slots (wrapping whole with the line, growing line height when taller, supporting nested text, `relayout` resizes, `memo` reuse, scroll-tracked hit testing, reading-order keyboard focus, AccessKit and web a11y mirror nodes, RTL visual placement, and hiding elided children across `truncate` / `max_lines`; `examples/playground` adds a `Text/Inline boxes` story).
