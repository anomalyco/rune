- **Windows: making a window no longer starts COM and the shell's taskbar list on the UI thread.** winit added every new window to the taskbar it is already on, which took `CoInitializeEx` and a `TaskbarList` COM object (about 7,800 µs and nine shell DLLs, `explorerframe.dll` among them) before the window's first frame; Rune now builds winit 0.30.13 as published plus that one change (`vendor/winit`, `vendor/winit.patch`, re-made by `scripts/vendor-winit.sh`). Window creation to the native window: 15,000 µs before, 8,600 µs after (p50, 12 alternating runs each). An app that builds Rune adds `winit` to its `[patch.crates-io]` as it does `wgpu-hal`.
