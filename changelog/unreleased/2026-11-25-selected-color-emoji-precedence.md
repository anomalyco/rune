- Text emoji fallback: colour emoji fonts explicitly selected by name in `AppSpec::families`, `Tx::set_font_families`, or `Family::Named` now take precedence over the system emoji font for `Route::Emoji` graphemes (default emoji presentation, `U+FE0F` sequences, ZWJ sequences, and regional-indicator flags) and avoid loading the system emoji font when every emoji in the text is already covered; monochrome text fonts still stay behind emoji fonts, and uncovered emoji still fall back to the system emoji font.
