- Added `El::a11y_action(id, label, f)` (repeatable) to declare custom accessibility actions on an element, published as AccessKit `CustomAction` entries (`Action::CustomAction`), serialized in `Runtime::accessibility_json()` (`"customActions"`) and `Runtime::a11y_json()`, exposed on macOS VoiceOver's Actions rotor via `NSAccessibilityCustomAction` (`vendor/accesskit_macos`), on Linux AT-SPI's `Action` interface (`vendor/accesskit_atspi_common`), and as non-tabbable hidden action buttons in the web accessibility mirror.
