- **Metal objects stay alive until their command buffers complete on Rune's native Metal backend.** Command buffers created with unretained references previously retired their keep-alive lists, staging buffers, views, and swapped buffer storage as soon as the GPU signaled the shared event rather than when Metal marked each command buffer completed, and `present` dropped `CAMetalDrawable` without keeping it until its command buffer finished. Resources and drawables now remain alive until `MTLCommandBufferStatus::Completed`, preventing use-after-free hazards on resize, teardown, and uploads, and allowing tests and apps to run cleanly under Metal API Validation (`MTL_DEBUG_LAYER=1`).
