- **Linux/Wayland: render window titles in system CSD headerbars by default via the new `wayland-csd-title` Cargo feature.** Plain system-decorated windows on compositors without server-side decorations (such as GNOME) now show their `AppSpec` / `Window::set_title` title in `sctk-adwaita`'s headerbar via `winit/wayland-csd-adwaita` (`ab_glyph` + fallback Cantarell font, Linux/BSD-only), and `vendor/sctk-adwaita`'s `read_system_config_early` starts the `gsettings` and `fc-match` title-font lookups off the main thread alongside the portal reads so first-window configure does not stall. Apps that draw their own chrome (`App::titlebar`) or want minimal Linux dependencies can opt out with `default-features = false`, keeping `wayland-csd-adwaita-notitle` frames and buttons without `ab_glyph`.
