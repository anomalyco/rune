- Web accessibility mirror: live siblings after a container whose child is playing an exit animation no longer vanish from the DOM mirror or become mis-parented under that container.
- Text input hit-testing: clicking, dragging and right-clicking in centred, end-aligned or right-to-left text inputs now lands on the clicked character rather than measuring from the left edge, and multi-line fields ignore single-line horizontal scroll offsets.
- Scroll occlusion: horizontal wheel, touch scrolling, fling, middle-click autoscroll and pointer-based keyboard scroll now follow the paint-ordered hit chain instead of scanning nodes in reverse order, so raised panels and anchored popovers block scrolling of viewports beneath them.
- Tooltip occlusion: an interactive overlay painted immediately after a non-interactive element with `El::help` now suppresses the underlying tooltip instead of letting it show through.
- Accessibility text geometry: AccessKit text runs and long-field drawn lines now apply `El::scale` to insets, origins and glyph metrics, and invalidate when the drawn scale changes.
- Right-to-left horizontal scrolling: accessibility `ScrollLeft` and `ScrollRight` actions now move in the visual direction in right-to-left viewports, and the web accessibility mirror undoes right-to-left horizontal scroll shifts with the right sign.
- Scaled link and highlight targets: `ElementInfo::target` for inline links and text highlights inside a scaled subtree now stays in unscaled layout coordinates.
- Scaled `Tx::keep_on_screen`: restoring a kept virtual row inside a scaled viewport now measures its saved position in unscaled viewport points instead of jumping by the scale factor.
- Exiting-node lookups and hover: horizontal `scroll_into_view`, sticky cover checks, accessibility `active_descendant`/`labelled_by`/`described_by` and hover/press tracks now ignore exiting subtrees (children of an exiting parent no longer hover or press while fading out), and pop-up menu key anchors match keyed suffixes across unkeyed wrappers as `Runtime::find` does.
- Sticky window layout reads: `Cx::window_layout`, `El::on_layout`, `El::on_screen_layout` and `Cx::selection_rects` now include sticky shifts on the element itself, matching anchored overlays and `Cx::caret`.
- Focus group and unmount fallback: selectable controls nested inside a focusable item of a focus group are no longer reported as members of the outer group in accessibility, and unmount focus fallback through moved stubs now skips collapsed zero-size controls.
