- Display event queues: added `App::on_display_events(pending, dispatch)` (also forwarded on `WindowSpec::on_display_events`), which checks an app's own event queue on winit's display at the end of each turn of a started, open window and runs `dispatch` with a `Tx` in the next turn when events wait; on Wayland the window also turns on winit's wake on every display read, so events a read left in the app's queue no longer wait for an unrelated wake.
