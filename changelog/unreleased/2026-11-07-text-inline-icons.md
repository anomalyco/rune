- **Text: inline icons, exact line boxes, and a browser's text gamma off macOS.** `El::inline_icon(at, InlineIcon)` sets a glyph or an image (a site's favicon) inline before a byte of a text, in room of its own, kept on the line of the word after it and centred on its letters, as a web page's icon before a link. `El::exact_lines` keeps a text's height its lines' own (22.4 points for a 22.4 point line) instead of rounding it up to whole pixels, so a stack of paragraphs lands where a page's does. `text::content_widths` gives a text's CSS min-content and max-content widths unrounded and without the spaces that end a line, as a table's automatic layout reads a cell. With font smoothing off (the default off macOS), glyph coverage now takes an exponent keyed to the text's luminance, as Chromium's grayscale text does on Windows: light text on a dark page draws heavier and dark text on a light page a little lighter.
