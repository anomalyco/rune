- Added opt-in `El::virtual_overscan(overscan, edge)` and `rune_kit::Table::virtual_overscan(overscan, edge)` builders so virtual lists can tune how many viewports stay mounted on each side (`overscan`, clamped to `0.0..=8.0`, default `2.0`) and how close the viewport may come before a window-move commit (`edge`, clamped strictly below `overscan` when `overscan > 0.0`, default `1.75` for `virtual_rows` and `0.5` for `virtualize`; non-finite inputs ignored), preserving today's defaults when unset.
