- **`App::run`, `run_windows_with` and their variants print a startup error and exit 1 instead of panicking** on native targets: no display over ssh or in CI, no Wayland or X11 server, or a headless flag in a release build without the `tooling` feature. Apps no longer need their own wrapper to turn that error into a clean exit; `try_*` still returns the error. wasm32 keeps the panic, which has no process exit.
