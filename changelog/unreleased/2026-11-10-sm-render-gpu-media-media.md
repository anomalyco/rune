- **`Recorder` and `Player` keep their native state as enums, which fixes two races.** A recorder is one phase that owns its device session, so a `cancel` that lands between a permission answer and opening the microphone can no longer leave the device recording for nobody, and a second `stop` (or a `cancel`) while the device finishes its file no longer marks the recorder `Failed("not recording")`. On macOS a paused video's seek back into the frame on screen replaces an earlier seek still in flight, so frames stop as soon as it lands instead of running for up to two more seconds. `RecorderState` and `PlayerState` are unchanged.
