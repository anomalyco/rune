- **procwatch: live heap by allocation site, for measuring builds (`alloc-sites`).** `Counting` samples one in every 32 KiB a thread asks for (a block of 32 KiB or more always), keeps each sampled block's call stack until it is freed, and with `PROCWATCH_ALLOC_SITES=<folder>` writes the live sites, the counted live and peak heap, every NT heap's regions and busy bytes, and the loaded modules to a file each time the event `Local\procwatch-alloc-sites-<pid>` is set (Windows). `rune`'s `alloc-sites` feature adds the GPU device's allocations by label. Ordinary builds compile none of it.
