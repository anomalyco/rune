- Linux/Wayland: Vulkan instance creation now loads only the compositor's GPU driver via `VK_LUNARG_direct_driver_loading` (exclusive mode) when no `WGPU_*` / `VK_*` override or debug/validation flag is set and matching ICD manifests are present, keeping a hybrid laptop's discrete GPU asleep without mutating process environment variables; any missing extension, unreadable manifest, older driver, or later adapter/surface failure falls back automatically to an unlimited Vulkan instance with all installed drivers.
