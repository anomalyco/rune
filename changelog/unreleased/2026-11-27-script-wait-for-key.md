- Added optional `"wait_s"` on keyed `--script` events (and `ScriptEvent::AwaitKey { key, wait_s }`): headless `--script` runs wait up to `wait_s` seconds for the element to mount while pumping zero-dt frames with the clock stopped, failing with `script: no element with key ... after ... s` on timeout; `--window-script` and `--desktop` ignore the field and events without `wait_s` behave as before.
