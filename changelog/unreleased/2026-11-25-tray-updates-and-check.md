- **`rune::Tray` adds live `set_icon`, `set_icon_name`, `set_title`, and `rect` queries, and `TrayItem::Check` adds checkmarked menu items.** `set_icon` updates the running icon on macOS, Windows (`NIM_MODIFY` with previous `HICON` cleanup), and Linux (`IconPixmap` + `NewIcon`); `set_icon_name` updates Linux SNI `IconName` (`NewIcon`); `set_title` sets monospaced-digit menu-bar text on macOS and SNI `Title` (`NewTitle`) on Linux; `rect` returns the icon's physical desktop `[x, y, width, height]` on macOS and Windows (`Shell_NotifyIconGetRect`) and `None` elsewhere; and `TrayItem::Check` (`TrayItem::check`, `TrayItem::checked`) renders native checkmarks on macOS, Windows, and Linux DBusMenu.
