- **`WGPU_ADAPTER_NAME` now means that adapter or none.** A name that matches no adapter, or names one that can't make a device now, is an error (`rune: no GPU: no GPU adapter matches WGPU_ADAPTER_NAME=...`); before, Rune said so and chose another GPU as usual. A window then stays on the CPU renderer and tries again; offscreen work gets the error. The name also finds software adapters through DXGI on Windows (`Microsoft Basic Render Driver` is WARP), without making a device on any other GPU: before, such a name made a D3D12 device on every adapter to look for it. Names that match a GPU pick it as before. `RUNE_GPU_LOG=1` prints every pick in a process, not only the first.
