- **`App::web_document()` makes a Rune app a whole web page.** The root lays out at its natural height and the browser scrolls the document, so trackpad momentum, the scroll bar, scroll keys, find-in-page, anchors and back/forward are the browser's own; the canvas stays fixed to the viewport and draws the band the page is scrolled to, rebuilding nothing as it scrolls. Above it the DOM mirror now carries landmarks, heading levels, paragraphs, links and images at each element's place, element ids from keys (`#views`), selectable transparent text the browser selects and copies (tinted with `--rune-selection`), and links and buttons Tab reaches (`--rune-focus`). See "A whole web page" in `WEB.md`.
