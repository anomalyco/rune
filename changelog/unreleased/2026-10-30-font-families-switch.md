- **`Tx::set_font_families(sans, mono)` switches the fonts behind `Family::Sans` and `Family::Mono` while the app runs**, for a UI or code font picker. Every window and overlay follows on its next frame. Each drops the layouts and glyph runs shaped in the old families, re-runs memoized subtrees and re-measures every text, then draws one frame. `rune::text::measure` and `ink` follow too, and so do rune-kit's table column widths and rune-mermaid's diagram layouts. A cache of measured sizes outside Rune should key on the new `rune::text::font_epoch()`. A missing family falls back as it does at launch, and asking for the families already in place does nothing. `Runtime::set_font_families` and `Runtime::font_families` do the same outside a handler. A 50 KB Markdown note re-shapes in about 34 ms. Apps change nothing.
