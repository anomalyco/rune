- Accessibility: a box that only takes a pointer's press (a pane that clears a selection, a scrim) is no longer a button to screen readers, only a control the keyboard reaches is; tree items and grid cells with a press are Tab stops under `Cx::web_focus`; every hover group lights while keyboard focus is inside it, so the controls it reveals show when Tab reaches them (`hover_group_focus` is now the same as `hover_group`).
