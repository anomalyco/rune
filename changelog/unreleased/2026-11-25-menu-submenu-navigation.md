- rune-kit: `MenuItem::on_submenu(|s, open| ..)` lets a menu open and close an item's submenu: Right, Return and Space on the row open it and move focus to its first item, Left or Escape inside it closes only the submenu and returns focus to the row (swapped right to left, as the chevron points; unchanged when the submenu flips for lack of room), and resting the pointer 200 ms on the row opens it while resting on another row of the same menu, disabled rows included, closes it. `Menu::on_close` and picking an item other than a checkbox or radio close the open submenus too, so the menu reopens with them closed. All `on_submenu` callbacks in one menu take the same state type. Menus without `on_submenu` behave as before. New `Tx::key_direction()` tells an `El::on_key` handler the focused element's layout direction.
