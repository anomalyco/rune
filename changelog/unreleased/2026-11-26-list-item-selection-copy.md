- Fixed list-item selection and copying in `rune` and `rune-kit::Markdown`: copying a single whole `El::copy_prefix` / list item now keeps its marker in plain text, HTML (`<ol><li>` / `<ul><li>`), and `Markdown::copy_source`, while partial intra-item selections drop the marker and `<li>` wrapper; `Markdown::copy_source` now slices whole selected list-item subsets verbatim from the Markdown source (preserving inline formatting, custom start numbers/delimiters, loose blank lines, task checkboxes, and nested lists); and dragging from a non-selectable list marker anchors selection at byte 0 of that item's text without making the marker selectable or moving any caret on a bare click.
