- **Share Linux fontconfig's system collection process-wide and add `rune::text::prewarm_system_fonts()`.** Replaced the per-thread `thread_local!` fontconfig collection in `rune-text` with a single process-wide `OnceLock<Mutex<Collection>>` so every thread shares one build, and added non-blocking, idempotent `rune::text::prewarm_system_fonts()` (respecting `RUNE_SYSTEM_FONTS=off` and `set_system_fonts(false)`) so Linux apps can warm fontconfig off the UI thread at startup or in `on_ready` without stalling the first fallback frame.
