- **Windows, debug builds and tests: a GPU submission that holds the GPU past 250 ms is reported as it happens.** Windows resets a GPU whose one submission runs 2 s, and an AMD GPU preempts nothing smaller than a submission, so work that a fast GPU finishes at once can reset a slow one. The vendored wgpu-hal times each D3D12 submission from when it could start (submitted, and the one before it done) to its fence's event, and `rune_gpu::budget` prints any past `BUDGET`: a test GPU of `rune-media` fails its test, Rune's own test binaries stop, and a debug app logs it. Release builds time nothing.
