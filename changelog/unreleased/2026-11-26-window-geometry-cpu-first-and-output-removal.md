- **`App::on_window_geometry`: CPU-first creation sample and Wayland output-removal detection (updates `vendor/winit.patch`; apps pinning `dev` must update their `[patch.crates-io]` `winit` rev) (#1017).** Unified native window creation callbacks (`on_created`, `on_window`, and `creation_geometry`) into `Host::announce_created` called by GPU creation, Linux CPU-first, and Windows CPU-first open paths so `CpuFirst::Auto` delivers the initial geometry sample before the first focus and drawn frame (and skips the synchronous first Windows CPU frame when the creation callback closes the window). On Wayland, vendored `winit` now filters removed `wl_output` globals out of `Window::current_monitor` and wakes `AboutToWait` on `output_destroyed`, `surface_enter`, and `surface_leave`, so disabling an output without `wl_surface.leave` reports `has_output: false` and re-enabling or keeping a second live output reports `has_output: true`.
