- **Hooks for hosting dynamically loaded views.** `memo::memo_with_hash` is `memo` with a version already hashed to a `u64`, for a caller across a C ABI. `Runtime::invalidate_memos_by_prefix` (and `Tx::invalidate_memos_by_prefix` from a handler or `poll`) drops one owner's cached subtrees, such as an unloading plugin's, without clearing the rest of the window's. `Cx::retype` and `Cx::absorb` are public, so a host can run a sub-view on a scratch context and keep or discard what it did.
