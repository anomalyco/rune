- **Kit Markdown: each block reads the way its own words do.** A paragraph or heading takes its first strong character's direction (outside code and URLs). A list takes its first item's, so its markers stay on one side. A quote's rule and a table's first column stand on the side its words start on, and a table cell keeps its column's alignment. Code blocks and diffs read left to right in any document. A block with no strong character reads the way the block before it does. `Markdown::dir_tentative` sets the direction a document reads in until its first words arrive (a reply's prompt's), so a streaming reply turns at most once. Inline code, URLs and the paths, calls and flags in prose are isolated left to right.
