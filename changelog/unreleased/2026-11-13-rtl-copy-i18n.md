- **Right-to-left copies and fallbacks.** A rich field's HTML copy says each block's direction (`dir="rtl"` or `dir="ltr"`, code `ltr`) when it holds right-to-left text, so Word, Mail and browsers lay it out as the field showed it; a left-to-right copy is unchanged. `rune-i18n`: a right-to-left locale's missing message is the source message between LRI and PDI, so an untranslated English sentence in an Arabic interface keeps its full stop at its end; plural categories keep their fallback to the locale's own `other`.
