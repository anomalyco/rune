- **`rune-fx` builds an effect's pipeline the first time a frame draws it.** `FxRenderer::new` and `add_format` no longer build all eight effect families in both blends up front, along with the mask pyramid and backdrop blur passes. Each pipeline for a format and blend is built the first time a layer draws with it, and those one `prepare` needs are built in parallel. On a cold Metal shader cache on macOS, a renderer that adds a layer format and draws one glow reaches its first frame in 71 ms instead of 1.80 s: `new` takes 0.1 ms instead of 919, and `add_format` takes no time instead of 865. Warm, that's 6.2 ms instead of 7.9. Each family, blend or format a later frame draws for the first time costs 20 to 150 ms on a cold cache, once. Pixels are unchanged.
