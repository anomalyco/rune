- **A scroll that teleports with no input is a jump.** The motion gate and `scripts/motion-audit/analyze.py` skipped every element flagged `scrolling`, and an instant `Tx::scroll_to_instant` is flagged for its frame, so an offset that landed in one frame with no input, bringing rows from just off screen into view, went unreported: the content's visible part stayed put and nothing showed on both frames to be seen moving. A one-frame scroll step is now excused only by an input on that frame or the one before, and the rows it brings into view count as what shows moving with the content, so it reports `jump` (or `offset-jump` when it carries three or more). A wheel, a tap's scroll and a glide stay quiet, as does a fold dropping rows above the window with the offset.
