- **Release builds link the headless agent tooling only with the new `tooling` feature.** `--snap`, `--tree`, `--script`, `--video`, `--strip`, `--html`, `--desktop` and the other headless runs were linked into every app, with a second instance of the runtime for the keycaps overlay: 3,480,576 B of `examples/hello`'s 26,666,496 B release exe. Debug builds keep them; a release build that wants them adds `features = ["tooling"]` (Rune's examples do, and `frame-profile` implies it). **Breaking for release scripts:** without it, a headless argument makes `run` return an error that says so, so a bundle or CI step that smoke-tests a release binary with `--list-scenes`, `--snap` or another headless flag fails (an app that unwraps `run` panics). Add `features = ["tooling"]` to the build those steps use, or smoke-test without headless flags. `--native --trace` is unchanged.
