- **Release builds link the headless agent tooling only with the new `tooling` feature.** `--snap`, `--tree`, `--script`, `--video`, `--strip`, `--html`, `--desktop` and the other headless runs were linked into every app, with a second instance of the runtime for the keycaps overlay: 3,480,576 B of `examples/hello`'s 26,666,496 B release exe. Debug builds keep them; a release build that wants them adds `features = ["tooling"]` (Rune's examples do, and `frame-profile` implies it). Without it, a headless argument makes `run` return an error that says so. `--native --trace` is unchanged.
