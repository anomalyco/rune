- **`FrameEncoded` says when a frame started and how fast the display refreshes.** `started()` is a drawn frame's start (after its drawable came), so frame-to-frame intervals no longer have to be pieced together from `at` minus the update and encode times, and `refresh_hz()` is the display link's rate on macOS (120 on ProMotion), else the monitor's, so an app's frame meter can count missed refreshes without guessing.
