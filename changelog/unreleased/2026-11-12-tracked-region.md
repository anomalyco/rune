- **`rune::Tracked<T>` and `rune::region(id, || ..)`: a region rebuilds only when a `Tracked` value it read was written (or a layout or caret read moved), and is otherwise reused whole without running its closure.** Every memo now records the `Tracked` cells it reads and is reused only while they hold; with no `Tracked` values nothing changes. Debug builds build every reused region again and print the first element that differs (`memo::region_warnings`), which is what reading state that isn't `Tracked` looks like.
