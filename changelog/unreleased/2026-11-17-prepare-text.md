- **`Tx::prepare_text(view, size)` lays a view's text out ahead, into the window's layout cache, without mounting it.** The view is measured as the window would measure it (at the window's size unless `size` says otherwise) in the window's next idle turn after its first frame, with scratch nodes, layout tree, ids and memo. It never runs while input waits. Nothing draws, hits, animates or is announced, and no handler runs. A view shown later with the same texts at the same widths finds them laid out, so its first frame shapes little. Prepared layouts no view holds are kept to 1 MiB by the cache's own count, the oldest pass's going first and never one a mounted text holds, and they all go at the window's next rest. One request is held, the latest, for the window whose state type the view reads.
