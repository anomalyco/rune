- **`set_app_icon_choice` gives the Dock the bundle's own icon, one image, or a light/dark pair on macOS.** `AppIcon::Bundle` passes `nil` to `setApplicationIconImage`, so the bundle's compiled icon comes back as macOS shows it. `AppIcon::Pair` swaps sides when `NSApp.effectiveAppearance` changes, with or without a window open, so an app that forces Light or Dark gets the matching side. `AppIcon::shown(dark)` says which image an appearance shows, without AppKit. On Windows, `Pair` checks both images and shows `light`; `Bundle` gives windows opened afterwards the icon resource from `set_app_icon_resource` if the app named one, else Windows' default window icon. On Linux, `Pair` checks both images and shows `light`; `Bundle` leaves new windows without an icon of their own, so the desktop entry's applies. `set_app_icon(bytes)` is unchanged.
