- Clipboard Copy Image: added `Tx::copy_image(&Image)`, `Tx::copy_image_then(&Image, on_result)` with `#[non_exhaustive]` `CopyImageError` (`NotReady`, `DecodeFailed`, `TooLarge`, `Superseded`, `Failed`), `ClipboardImage::from_rgba` (synchronous straight-alpha sRGB RGBA8 PNG encoder), `Image::to_rgba`, and `Pixels::to_rgba` (plus internal `ClipboardWrite::pixels`). Copies PNG, JPEG (EXIF-oriented, ICC converted to sRGB), WebP/GIF (frame 0 for animations), native AVIF stills, and SVG (`load` at rounded intrinsic size up to 4096 px/side, `svg` at smaller raster size) off the event thread on native workers (with generation/revision late-overwrite protection, Windows registered `"PNG"` + `CF_DIBV5` without re-decoding, and no empty-text clobber on bad PNGs) and via `ClipboardItem` `Promise<Blob>` off the browser input turn on web; opaque 8-bit sRGB pixels round-trip bit-exactly while translucent pixels pass through premultiplied 8-bit sRGB mip 0.
