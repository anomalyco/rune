- Windows DX12: removed the automatic DirectComposition-to-HWND fallback and its vendored `wgpu-hal` hunk added in #1829, following Chromium (CL 6215560, CL 6324950). The explicit `WGPU_DX12_PRESENTATION_SYSTEM` switch (`visual` or `hwnd`, via wgpu's `Dx12SwapchainKind::with_env`) stays; running a Windows build under Wine or Proton without DirectComposition now requires setting `WGPU_DX12_PRESENTATION_SYSTEM=hwnd` explicitly, and a failed DirectComposition setup under Wine appends that hint to the window error (probed via `ntdll.dll` `wine_get_version` only on the error path, never at launch).
