- Accessibility: added the `"feed"` role (AccessKit `Role::Feed`, set-like container, mirrored as `role="feed"` on web and static HTML export); ordered-set items (such as `"article"` rows in a virtual `"log"` or `"region"`) now carry their own `size_of_set` when their container is not an ordered-set container, and the web DOM mirror and focus proxy emit `aria-posinset`/`aria-setsize` for virtual and explicit ordered-set items including non-button `<article>` elements.
