- Shaders: vendored `naga 30.0.1` with `vendor/naga.patch` (re-made by `scripts/vendor-naga.sh`) so valid WGSL shaders that declare `override`s and index `let`-bound constant vectors or composites no longer fail `naga::back::pipeline_constants::process_overrides` with `ExpressionAlreadyInScope` or `NotInScope` (gfx-rs/wgpu#7793). **Apps that build Rune should add `naga = { git = "https://github.com/anomalyco/rune", rev = "<the Rune rev they pin>" }` under `[patch.crates-io]`** in their workspace root `Cargo.toml` (Cargo does not inherit patches from a dependency; without it they build against crates.io `naga` and can use `const` instead of `let` for those bindings as a workaround).
