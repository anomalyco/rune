- **`rune::displays()` reads the displays while the app runs.** Called on the UI thread (a handler, an update, `on_ready`), it asks the system for the monitors again through an open window and returns them with the fields a `run_windows` factory gets, so an app can find a monitor plugged in after launch and `open_window` a `WindowOptions::overlay` on it. The factory's list comes from the same code. With no window open it returns the displays last read; headless runs return their virtual desktop. Rune does not yet report when displays change.
