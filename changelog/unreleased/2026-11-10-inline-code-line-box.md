- **Inline code no longer grows the line it sits in.** A monospace span at the text's line height has a box as tall as the line's strut, but placed by its own ascent and descent: at 13 px IBM Plex Mono's round to 13 and 4 where Inter's round to 13 and 3, so a 13/16 line with code in it laid out 17 tall and a markdown table row with inline code stood 38 pt where Chromium's stands 36. Each monospace span no larger than its text now takes a line height that keeps its box inside the strut (`text::inline_fit`), as Chromium's line keeps the strut's 16 px; its glyphs stay on the baseline. Code larger than its text keeps its own box.
