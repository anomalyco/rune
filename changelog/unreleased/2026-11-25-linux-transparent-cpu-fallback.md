- **Linux transparent windows fall back to `CpuPainter` without Vulkan:** on Linux machines where pre-swapchain GPU startup fails (such as no Vulkan driver installed), visible transparent windows under `CpuFirst::Auto` or `CpuFirst::Only` (with `WGPU_ADAPTER_NAME` unset) now fall back to `CpuPainter` with alpha buffers (`wl_shm` ARGB8888 on Wayland; 32-bit ARGB TrueColor on X11, or a 24-bit opaque window with the theme background if the X server has no 32-bit visual) instead of exiting with a surface error. The fallback starts with `GpuJob::Failed` so Vulkan is not retried in a loop, and once a Linux CPU window's GPU job has permanently failed, degradable `NeedsGpu` features paint without their GPU-only modifier instead of aborting. Machines that can create a GPU surface, `CpuFirst::Off`, and pinned `WGPU_ADAPTER_NAME` adapters behave as before.
