- **The motion gate takes a `.motion(Spring::NONE)` written on an element as an authored instant change.** Its colours (text aside), corners, shadow and blur can snap without a `snap`, `flash` or `changes-twice` finding; `El::blur_motion(Spring::NONE)` does the same for blur alone. A `Spring::NONE` inherited from a parent, set from a theme or token, or applied under Reduce Motion still reports. New `El::token_motion` sets a spring a theme chose without that mark; rune-kit's components now use it for their `Motion` tokens.
