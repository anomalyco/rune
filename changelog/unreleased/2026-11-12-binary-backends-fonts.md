- **Windows draws with D3D12 alone, and an app that brings its own fonts carries no Inter.** wgpu's Vulkan backend is no longer compiled for Windows (it was only the fallback when DXGI listed no hardware adapter; such a machine now draws on WARP, D3D12's software adapter), so `ash`, `libloading` and the Vulkan backend leave the binary, and the GPU thread no longer makes a DXGI factory of its own to decide between the two. Native builds bundle Inter only with the `embedded-fonts` feature, as web builds already did: an app that sets `AppSpec::fonts` and turns default features off drops about 1.25 MB. `rune-fx` and `rune-knobs` no longer turn Rune's default features on.
