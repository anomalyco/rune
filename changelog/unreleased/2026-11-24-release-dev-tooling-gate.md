- Tooling: release builds without Rune's `tooling` (or `hot`) feature now leave the process command line untouched for the app (`extra_args` receives every argument, including `--help` and malformed flags; `is_headless()` returns `false`), decode OS arguments lossily instead of panicking on non-UTF-8 input, and ignore an ambient `OTEL_EXPORTER_OTLP_ENDPOINT` unless `RUNE_PERF=1` is set. Debug builds, release builds with `tooling` (which Rune's examples enable via `keys-overlay`), and explicit `App::args` / `run_windows_with_args` lists keep parsing Rune's flags.
