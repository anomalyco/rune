- **`InlineIcon::label` and `InlineIcon::help`: a name and a tooltip for an icon set inline in text (`El::inline_icon`).** An inline icon was decoration only: assistive technology skipped it, and resting the pointer on it showed nothing. `label` gives it a name, as an `<img>`'s `aria-label` does: the text's element gains an image with that name in the accessibility tree, placed on the icon's square. `help` gives it a tooltip of its own, as `El::help` gives an element (an HTML `title`): the same delay and look, under the icon, shown over any help the element has; a named icon also reads it as its description when it differs from the name. Nothing changes for an icon that sets neither.
