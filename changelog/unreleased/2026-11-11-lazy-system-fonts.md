- **A text system starts with the app's own fonts alone; a system font loads the first time a text needs it.** `TextSystem::new` no longer lists the system's font folders or loads the CJK and symbol fonts (49,253 µs p50 per window on a Windows laptop, 610 font files opened); it takes about 190 µs. The first text with a character the app's fonts lack loads that font as it shapes (about 3,000 µs on that laptop, no missing-glyph frame). On Windows the file comes from Windows' own fallback (`IDWriteFontFallback::MapCharacters`) or, for a family asked for by name, from DirectWrite's system collection, so `C:\Windows\Fonts` is never listed and only the files a text needs are opened; characters no app font covers now find a font in any script, where before they drew as missing glyphs unless they were CJK, symbols or one of five scripts.
