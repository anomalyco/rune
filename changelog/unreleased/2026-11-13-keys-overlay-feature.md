- **`--keys` and `--pointer` in a release build need the new `keys-overlay` feature (it includes `tooling`).** The keycaps and click ripples draw with a second instance of the runtime, which a release app with `tooling` linked whether it drew them or not: 1,867,264 B of `examples/hello`'s release exe built with `tooling` (27,318,784 to 25,451,520 B). Debug builds keep them; Rune's examples, rune-kit's, rune-fx's and rune-light's take `keys-overlay`. Without it, `--keys` or `--pointer` stops the run with a message that names the feature.
