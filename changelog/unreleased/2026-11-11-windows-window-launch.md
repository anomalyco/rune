- **Windows: a window reaches its first frame without OLE, a PNG icon or an adapter probe.** Windows are created with winit's drag and drop off (its OleInitialize and RegisterDragDrop cost a window about 8,400 µs and six shell DLLs inside CreateWindowExW) and Rune registers its own OLE drop target once the window has shown, which reports where a drag is at each step as macOS's does; `set_app_icon_resource` takes the windows' icon from the executable's icon resource instead of decoding and resizing a PNG at launch; the single-instance pipe is named from the token's SID rather than `GetUserNameW` (which loads SspiCli and calls the LSA); and whether DX12 is there is read from DXGI's adapter list instead of wgpu's `enumerate_adapters`, which made a device on every adapter, the discrete GPU and WARP included (987,254 µs p50 on a hybrid laptop).
