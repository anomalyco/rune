- Luau UI: Rune's own nodes (`row`, `col`, `box`, `text`, `spacer`, `virtualList`): an unknown prop, or a handler or list prop on a node that doesn't take it, was a warning once per script and is now an error in debug builds (the surface shows its error card), still a warning in release. An app's host nodes that list their props (`HostNode::props`) behave the same; before, a host node dropped an unknown prop without a word (`autofocus` on a button, rune-desktop #664).
