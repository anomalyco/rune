- `rune-kit`: `SegmentedMetrics` gains `inset` (a groove between the `SegmentedControl`'s edge and its segments, so the selected pill sits inside it, `height - 2 * inset` tall with `radius - inset` corners) and `gap` (space between segments). Both default to 0, so controls look as before; code that writes `SegmentedMetrics { .. }` in full without `..SegmentedMetrics::kit(&k)` needs the two new fields.
