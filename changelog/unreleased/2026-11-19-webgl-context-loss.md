- **Web: WebGL2 handles uncaptured errors, optional pipeline error scopes, and `webglcontextlost` / `webglcontextrestored`.** Uncaptured `wgpu-core` errors on WebGL2 now log to `console.error` instead of a silent `eprintln!`, lazily built optional pipelines (`Rgba16Float` layers, `PlusLighter`, layer blur) check `wgpu-core`'s synchronous error scopes so unsupported formats fall back cleanly, and WebGL2 context loss prevents default and recovers on `webglcontextrestored` (painting on the CPU canvas in the meantime for full-window pages, or pausing inline/document pages until restore).
