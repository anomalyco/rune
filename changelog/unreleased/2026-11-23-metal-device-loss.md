- **macOS: a GPU hang no longer leaves a window black for good.** When the GPU times out on a queue's work, macOS ignores everything that queue commits after, and the Metal backend took the failed command buffers as finished, so the window kept drawing into a queue that never ran. A command buffer that fails with a timeout, revoked access or a removed device now loses the device (`Device::set_device_lost_callback`, before a no-op), and the window makes a new device and surface as after any device loss. The vendored wgpu-hal reports the same loss for a stock wgpu Metal device.
