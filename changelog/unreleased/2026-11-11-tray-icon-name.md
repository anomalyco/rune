- **`TraySpec::icon_name` gives a Linux tray icon a freedesktop icon theme name to draw.** The StatusNotifierItem's `IconName` property serves it, so a host that resolves theme names draws that icon and may recolour a symbolic one to fit its panel; `IconPixmap` is still served unchanged for hosts that don't, and the name stays empty unless an app sets one, so existing trays look the same.
