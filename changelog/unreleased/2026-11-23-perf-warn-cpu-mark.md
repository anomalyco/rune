- Debug stall warnings on Windows: a callback that blocks in the first 20 ms after the process first reads the thread's CPU clock (`init`, the first `update` or `poll`) now warns. The stall timer keeps a raw CPU mark and converts it once the cycles' rate is known; before, it had no CPU reading at the start and skipped the callback. A callback that ends with no CPU reading no longer counts as 0 ms of CPU.
