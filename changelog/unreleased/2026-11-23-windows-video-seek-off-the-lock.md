- Windows video: dragging a seek bar no longer freezes the UI. The decoder thread moved its Media Foundation source (`SetCurrentPosition`) while it held the lock the UI thread takes in every frame that draws the clip and for every seek, so each seek of a drag stalled the UI for a whole source seek. It now takes the newest seek, releases the lock, moves the source, and looks for a newer seek before it reads anything, so only the newest seek of a burst is decoded.
