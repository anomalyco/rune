- GPU memory policy: added `rune::GpuMemoryPolicy` (`MemoryUsage` default, `Performance`, and `Manual { block_size }`), `rune::set_gpu_memory_policy`, and `App::gpu_memory_policy` so apps can configure wgpu's suballocator memory hints at startup across windows, overlays, and prewarmed or parked devices (honored by D3D12 and Vulkan; ignored by native Metal, wgpu Metal, and web; resources larger than a `Manual` block range still use dedicated allocations).
