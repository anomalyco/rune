- **`El::drawn_rect_into(&Live<[f32; 4]>)` writes where each frame draws an element into a live value, with no handler and no commit.** It tracks every frame the element moves, through a scroll, a glide (`Tx::scroll_to`) and springs, where `on_drawn_layout` reports only once motion rests and commits unless its handler says `Tx::live_only`. An element bound to the value with `live_rect` follows a frame behind.
