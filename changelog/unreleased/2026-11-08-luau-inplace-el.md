- **rune-luau builds each `ui.*` node in its arena slot.** Props set the element there as Luau's iterator reads them, through Rune's in-place `set_*` builders, and children move from their slots straight into the parent, so a node is never copied whole and the intermediate props struct is gone. The few props that depend on others (`pad` beside `pt`, `center`, `corners`, `selected`, `disabled`, a text node's style and colour, `border`, scrolling, the key a press handler reports) still land after the whole table is read, so the result doesn't depend on the order the table is walked in.
