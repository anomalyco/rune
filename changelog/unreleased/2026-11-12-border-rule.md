- **`rune::rule(width, c)`: a rule laid out as a CSS border is.** A `border-top` on an empty box: its width snapped to device pixels as a border's is (one whole pixel under one) and that many pixels of room in its column, so a list split by `border-bottom: 0.5px` rules ends where Chromium's does: 1, 0.8 and 0.667 points a rule at 1x, 1.25x and 1.5x, where `el().h(0.5)` takes 0.5 at every scale.
- **A markdown code block's border takes its room.** Its 0.5 px ring is laid out as Desktop's `.highlights` border is, a device pixel each side inside which the padding sits, so a block is two device pixels taller and what follows it sits where it does in Chromium.
