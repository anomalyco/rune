- **Windows: FXC (`d3dcompiler_47.dll`) loads the first time a shader compiles from source, not when the GPU instance is made.** Rune's uber shader is precompiled DXBC, so a window that draws only with it never loads the compiler (its load alone took 1,699 µs p50 on the GPU thread before the first frame on a Windows laptop). The vendored wgpu-hal (`vendor/wgpu-hal.patch`) holds FXC in a `OnceLock` filled by the first compile; a missing `d3dcompiler_47.dll` now fails that compile instead of the instance.
