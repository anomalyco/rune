- Web: WebGL2 pages draw again. `clip.wgsl` and `rune-media`'s `video.wgsl` decoded half-float fade widths with a vector `select` of `u32`s, which naga writes for GLSL ES 3.00 as `mix(uvec2, uvec2, bvec2)`, an overload WebGL2 doesn't have, so the uber and atlas fill pipelines failed and the canvas went blank. Each half now decodes with scalar selects, still without `SHADER_FLOAT16_IN_FLOAT32`, and a test translates every shader the web build makes through naga's WebGL2 GLSL back end.
