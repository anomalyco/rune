- **macOS: any failed Metal command buffer loses the device, as in Dawn.** Before, only a timeout, revoked access or a removed device did; a buffer the GPU discarded while recovering from a hang, or one that failed for another reason, counted as finished though its work never ran. Now any command buffer that ends in error loses the device, in Rune's Metal backend and in the vendored wgpu-hal for stock wgpu Metal devices, which now checks every command buffer of a submission and never reports a failed one finished before the loss. This is gfx-rs/wgpu#10875's rule, kept until a wgpu release has it.
