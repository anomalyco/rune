- **Every Rune app ends fast when it quits, and its window goes at once.** The fast exit (`rune::fast_exit`) is now the default: once the quit's hooks have run, the process ends without dropping its windows, devices or threads, so code after `run` doesn't run; an app that needs it calls `rune::orderly_exit()`. The last window's host is no longer dropped before the process ends (its window, swap chain and device took ~37 ms to tear down), and the windows are destroyed at once: `WM_CLOSE` to window destroyed 68,512 → 12,475 µs p50 for a plain `rune::run` app.
