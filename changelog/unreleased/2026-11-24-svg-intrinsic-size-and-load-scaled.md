- `Image` and `ImageCache`: added `Image::intrinsic_size` to expose an SVG document's resolved CSS-pixel dimensions independently of its decoded raster size (falling back to mip 0 dimensions for rasters), and `ImageCache::load_scaled(bytes, size_pt, scale)` to downsample raster images to their target device-pixel draw size (decoding only frame 0 of animations, never upscaling) before mip generation.
