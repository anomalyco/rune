- **A layer target waiting to be reused binds the current atlas and outline store only when a layer takes it back.** A new outline texture no longer makes a bind group for every parked target, twice on a frame that also replaces the atlas; a parked target keeps the generation it was made against, binds once on the frame that takes it in, and one never taken again costs nothing. Text that needs the taller store still draws through it: a target taken back for text that outgrew the texture binds the new rows before it draws.
