- **`Host::give_back` and `OverlayCore::give_back` now drop GPU `Renderer::images` textures when resting or hidden.** Idle rest (`GiveBackUnused`) prunes GPU textures (and layer image bind groups) for image atlas pages that `ImageAtlas::rest` already freed, while keeping visible pages resident; hidden or covered rest (`GiveBackAll`) clears all GPU image textures before retiring GPU work, and the first drawn frame on wake recreates and re-uploads them automatically.
