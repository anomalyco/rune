- **`Cx::web_focus` gives a ported web page the browser's keyboard focus.** Every pressable control (an `on_press` element whose role is button, link, tab, checkbox, switch, radio or combobox) is a Tab stop in document order and takes focus when clicked or right-clicked, as an HTML `<button>` does, unless it says `focusable(false)` or is disabled; a focused one presses on Return as well as Space, and one with `preserve_focus_on_press` leaves the field focused. A modal that opens focuses its `El::autofocus` control, else its first text field, else itself, so Tab enters it at its first control rather than its close button. Tab with nothing focused goes on from the element last focused or pressed, as a browser's sequential focus navigation starting point does. Off by default.
