- **macOS: Rune's own Metal backend finds its precompiled built-in pipelines whatever a checkout's line endings are.** A built-in shader's key hashed its WGSL as checked out, so a checkout with CRLF `.wgsl` files (made before `.gitattributes`, or an archive) missed every one and compiled it at run time (naga, then Metal's front end). The key now reads each `\r\n` as `\n`; LF text hashes as before, after one scan for `\r`, and the table is unchanged.
