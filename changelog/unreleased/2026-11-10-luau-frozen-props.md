- **Luau: a node built from a frozen props table (`table.freeze({ ... })`) is decoded once and copied after that**, its style shared until written, so a script that keeps its styles in frozen tables skips the table walk, the prop decoding and the setters on every rebuild (a template holds while its colours resolve the same; `shadow`, `onPress` and `onHover` tables decode each time). Host nodes read their props without copying the keys, `view:Memo` keys no longer allocate, and `Data` tables cross into a script through the C API. Rune gains `El::set_content`, which gives a styled text element new words, and `memo::as_next_build`, which lets tooling time a rebuild as the following frame would see it, its unchanged inner memos reused.
