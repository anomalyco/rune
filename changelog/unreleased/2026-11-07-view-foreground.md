- **A view can name its theme's text colour and focus ring.** `Cx::foreground(color)` is the colour text, icons and text fields that aren't given one draw in, as CSS `color` on a page: a field's placeholder at 40% and its selection at 20%, so a `text_input` left uncoloured stays readable in a light theme instead of drawing white on white. `Cx::focus_ring(width, offset, color)` replaces AppKit's 3 point ring on focusable elements that set none of their own, still for keyboard focus only (`:focus-visible`). `El::focus_within_ring` draws a ring while focus is on an element or inside it however it got there (`:focus-within`), the 1 point ring a field box shows.
