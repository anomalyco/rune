- **`ImageCache::url` loads an image by URL; on web the browser fetches and decodes it.** Decoding uses `createImageBitmap` off the main thread, so WebP and AVIF work on web, and the pixels land through the same mip path as `ImageCache::rgba`, with the cache's waker drawing the frame. On web `ImageCache::file` now fetches its path relative to the page instead of failing. Native `url` takes a path or `file:` URL and refuses network URLs (Rune has no HTTP client); native `file` is unchanged.
