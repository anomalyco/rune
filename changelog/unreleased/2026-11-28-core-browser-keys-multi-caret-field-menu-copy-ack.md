- Core editor, input, and clipboard APIs: added `Key::BrowserBack` and `Key::BrowserForward` (with `ChordKey`, winit, web `bridge.js`, Android `KEYCODE_FORWARD`, and Linux layer-shell XKB `XF86Back`/`XF86Forward` mappings, ignored by focused text fields); added `Tx::copy_then`, `Tx::copy_rich_then`, and `#[non_exhaustive]` `CopyError` (`Superseded`, `Failed`) mirroring `Tx::copy_image_then` across native workers and web; added `El::field_menu` + `FieldMenuContext` (and `rune-kit` `TextInput`/`TextArea`/`TextField` forwarders) to extend Rune's built-in field context menu across native, fallback, and web paths while making `rune::spell::{misspelled_at, suggest, learn}` public; and added `TextEdit`-owned multi-caret editing (`Caret`, `carets`, `has_extra_carets`, `add_caret`, `add_selection`, `set_carets`, `clear_extra_carets`, `add_caret_above`/`add_caret_below`, `add_next_occurrence`, `selected_all`) across typing, navigation, line-matched paste, copy/cut, atomic undo/redo + history JSON, IME commit, Escape collapse, paint, and `Cx::field_selection_rects`.
