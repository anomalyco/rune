- **`scripts/web-build.sh`: `--dev`, `--watch` and `--no-html`, and it keeps your own page.** `--dev` builds the debug profile without debug info, with dependencies at opt-level 1, in a `web-dev` target folder, skipping `--opt` (about 2 s for a one-line change to `web-hello`, against 12 s for release). `--watch` rebuilds when a workspace member's files change, and the generated page reloads itself through a `reload.js` that polls `.stamp`. `index.html` is now written only if it is missing or still carries the generated-by comment; `--no-html` never writes it. The script builds with the toolchain's own cargo (`rustup which cargo`, or `CARGO`) instead of a `cargo` on `PATH`, and says so if the wasm is missing afterwards.
