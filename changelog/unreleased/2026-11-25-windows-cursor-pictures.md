- **Windows: `Cursor::Grab`, `Cursor::Grabbing`, `Cursor::ZoomIn` and `Cursor::ZoomOut` show Chromium's pictures.** Windows has no system cursor for them, and winit's stand-ins were the four-way move arrows for both hands and the plain arrow for both magnifiers, so a zoomed picture read as `move` and a picture that opens larger gave no hint. They now draw Chromium's Windows cursors (its 32 px bitmaps with their hot spots, resampled nearest-neighbour to the monitor's scale), as `Cursor::Cell` already did. macOS, Linux and the web are unchanged. `Cursor::ResizeColumn` and `Cursor::ResizeRow` stay the system's two-way arrows: Chromium's own invert the screen under them, which a colour cursor can't.
