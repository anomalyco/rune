- **Windows: the first key or click doesn't build winit's keyboard-layout table.** winit builds its table for the keyboard layout (every virtual key through `ToUnicodeEx`, 8-10 ms) on the first key or mouse message the window handles. It is now built on a thread of its own as the event loop starts (`winit::platform::windows::warm_keyboard_layout`, in `vendor/winit.patch`). OpenCode, a click and Escape posted as the first frame showed: the click handled 13-15 ms after the frame before, 4-8 ms after; the key 19-20 ms before, 9-14 ms after.
