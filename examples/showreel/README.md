# showreel

The scene set behind Rune's README video.

Run one scene with `cargo run --release -p showreel -- --scene <name>`; record it with `--video out.mp4 --size 960x540 --scale 2 --fps 60 --duration D`.

Scenes: `word`, `card`, `deploy`, `glass`, `fire`, `pricing`, `ask`, `shock`, `keys`, `tabs`.
