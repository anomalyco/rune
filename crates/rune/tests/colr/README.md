# COLR test fonts

- `test_glyphs-glyf_colr_1.ttf`: the "COLRv1 Static Test Glyphs" font from [googlefonts/color-fonts](https://github.com/googlefonts/color-fonts/blob/8b22116eec7ac92d1f2b99f2a4c03c7e07f27966/fonts/test_glyphs-glyf_colr_1.ttf), unmodified. Apache License 2.0, in `test_glyphs-LICENSE.txt`. Its glyph descriptions are in that repository's `glyph_descriptions.md`.
- `Noto-COLRv1-grinning.ttf` and `NotoColorEmoji-grinning.ttf`: U+1F600 subset with fontTools from `Noto-COLRv1.ttf` and `NotoColorEmoji.ttf` of [googlefonts/noto-emoji v2.051](https://github.com/googlefonts/noto-emoji/tree/v2.051/fonts), the same artwork as COLRv1 paint and as CBDT bitmaps. SIL Open Font License 1.1, in `NotoEmoji-OFL.txt`.
